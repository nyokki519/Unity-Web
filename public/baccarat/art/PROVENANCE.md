# VESPER original artwork

2026-10-29 original art direction and assets for Unity MIX.

- `salon.webp`: new image-generation output, original quiet walnut/emerald/brass hotel salon. No third-party photograph, logo, text or audio copied. Original master: `docs/art-source/vesper-salon.png`.
- `jack.webp`, `queen.webp`, `king.webp`: crops of new original three-portrait engraved court artwork. Prompt specified original faces, botanical regalia, no text/numbers/suits/logos/known character. All52precise indices and all numeric pips/suit cartouches are programmatically composed by `tools/generate-baccarat-cards.py`, not image-generated. Four suits share each court portrait, not12individually commissioned illustrations. Original master: `docs/art-source/vesper-courts.png`.
- `felt.webp`, `leather.webp`, `paper.webp`: deterministic original Pillow/numpy material maps, source `tools/generate-baccarat-materials.py`; approximated surface detail, not material scans.
- `unity-engraving.png`: monochrome/transparent derivative of existing community heart-and-cup mark `public/assets/unity-mark.webp`, use authorized by user. Not the Unity Technologies logo. Alpha extracted from luminance to remove beige square surround.
- Back: original botanical/guilloche vector geometry,180degree mirrored entire half. Shared for all cards/decks. Court image has no betting logic meaning.
- Fonts: CSS system/Georgia/serif fallbacks only; no downloaded font software. Sound: previously documented original cafe lounge and synthesized foley, no new third-party recordings.

Generated assets are project art assets; this is a provenance record, not a guarantee of exclusivity in any jurisdiction. Characteristic branded source expression was not requested or copied.
