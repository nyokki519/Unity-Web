# v1.2.0：強化の重なりによる火力過多の修正

## 調整方針と原因

ユーザー報告：見た目の強化は良いが、チート級の火力でバランスが崩れた。
1.1.0では威力25ポイント/レベル、連射22ポイント/段階、追加射線、大口径の威力1.6倍、追加砲、補助攻撃の強化が乗算・加算されていた。固定条件の最大強化比較で、代表6武器は旧版の約2.8〜3.8倍、全20武器では約2.7〜5.8倍のDPSとなっていた。

敵HPの一律増加は初期装備や装備差に不利となり、無用な硬さが増えるため不採用。全19種の補給・大きい弾・反射軌道・旋回砲・防壁・HUDは維持し、攻撃の数値と分配を修正した。敵のHP/弾幕/速度/報酬やドロップは変更していない。プレイヤーの装備量に応じた敵の裏補正も行わない。

## 実装

- 主砲の基礎威力：1段階25→11ポイント、連射：22→12ポイント（元の成長率）。
- 大口径：直径と衝突半径の拡大は維持し、別枠の威力乗算を除去。命中範囲の強化として区別する。
- 通常弾：見た目は最大6射線、合計威力は旧版の最大5射線に合わせて配分。
- 追加側射：主攻撃のパターンごとの標準威力を基準に、既存弾と追加弾へ配分。射線を増やすほど威力も何倍になる掛け算を抑える。通常弾と散弾の元の成長は維持。
- 光線・誘導補助：0.65秒間隔の見た目は維持。1発の威力を元の1.2秒間隔時のDPSに合わせて縮小。
- 反射砲：総発射威力を12/16/20ダメージ毎秒相当に設定し、2/4/6発に分配。反射と貫通による複数敵への効果は残る。
- 旋回砲：総発射威力を16/20/24ダメージ毎秒相当に設定し、2/3/4基に分配。見た目・発射間隔・発射位置は維持。
- 防壁：1回の被弾を防ぐ既存仕様を維持。
- 表示は「基礎威力100→111%」「命中範囲を拡大」など実仕様と一致させた。
- シミュレーション版1.2.0。旧リプレイは異なる戦闘ルールで誤再生せず再生不可。所持資金・装備・強化・実績などの進行セーブは維持。

## 検証と限界

- 単体テスト：347件成功。火力の原成長率、拡幅時の威力配分、新補助の総威力上限、大口径の非乗算化を検証。
- 全5航路：テスト用操縦プログラムで4回クリア（EASY2/NORMAL2、約932〜998秒）。全件でリプレイの最終状態・統計・報酬計算が一致。
- ブラウザ：耐久ゲージ、基礎威力100→111%、新19補給、使用可能状態、375/390/414px、375×667pxの操作領域を確認。
- 既存の工廠保存・タッチ移動・手動射撃・UIリプレイ・一時停止・次航路のブラウザ回帰も実施。
- 他ゲームのソースは変更なし。全体テストにはレトロ・交流ゲーム・チンチロなど既存回帰を含む。
- 物理iPhone・Safari実機と人間による長時間の難易度評価は未確認。統計上の最適解や万人に適した難度とは断定しない。
