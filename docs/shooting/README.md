# Unity SHOOTING / 翠星航路 v1.2.0

Unity MIXのホームの「シューティングで遊ぶ」から入る、登録不要の1人用縦スクロールシューティング。
公開URL: https://unity-mix.onrender.com/shooting/index.html

## 遊び方

1. 「出撃準備」で機体・主兵装・支援機・難度を選び発進。
2. スマホは画面ドラッグ、PCは矢印/WASDで移動。通常は自動射撃。自動射撃OFF時は画面の射撃ボタンを長押し、またはSpace/Z。
3. Shift/「精密」で低速・当たり判定表示。X/ボム、C/特技、V/解放。精密ボタンはタップ切替。ボムは有限、特技はエネルギー、解放はゲージ100を消費。
4. P/S/W/L/M/Oなどを回収し戦闘中に強化。画面上部に進むと自動回収。組合せを満たすと武器が進化・融合する。
5. 各航路の中ボス・ボスを倒す。クリア時は画面内の残り補給を回収し、結果→次の航路へ。1航路は約3～5分、全5航路は約15分が目安。
6. 工廠で8機体・20武器・15支援機を解放。兵装/支援機個別の最大5段階開発、装甲/エネルギー/回収/火力の恒久強化がある。戦闘中の主砲強化は最大8段階。

初期は3機体・3武器を利用できる。任務で得たCR/5等級素材で拡張する。スコアアタックは機体/兵装/支援/強化/航路/難度を固定。デイリーは日本時間の日付シード、固定装備・HARD・日替わり航路。タイムアタックとボスラッシュも選べる。

無被弾または累計12部位破壊で最終航路の真の守護者へ分岐。全航路突破で隠し航路と秘密装備の開発条件を解放する。秘密装備は上位素材も必要。通常/無傷/真の中枢のエンディングがある。

進行・設定・戦績・最後の出撃リプレイはこのブラウザのローカル保存。アカウントやオンラインランキングではなく、別端末へ自動同期しない。保存拒否/容量不足時は画面で通知し、その場のプレイは継続可能。

## 実装範囲

- WebGLのオリジナルSF描画、6背景、多重スクロール、機体/敵/部位/支援機/弾/警告/爆発など。
- 8機体、20武器、15支援機、19アイテム、12通常敵の行動、20弾幕、5航路＋隠し航路。
- 中ボス/最終ボス/HPフェーズ/部位破壊/発狂/照射予告/時間制限/真の守護者。

## 技術選定・起動

既存のNode24/ES Modules/Three.jsを再利用。Phaser/Vite/新規バックエンドの導入は避け、ゲーム専用の2D処理と正射影WebGL描画を分離した。既存の交流ゲーム・ルーム・チンチロ・レトロ版には依存しない。外部CDN、APIキー、課金、有料サービス、新規環境変数は不要。

```sh
npm ci
npm start
# http://localhost:3000/shooting/index.html
```

既存環境ではPORT/DATA_PATHを従来どおり指定可能。ゲームのセーブはサーバーDATA_PATHではなくブラウザ内。

### 性能の限界

PC ChromiumのSwiftShader（ソフトウェアGPU）/390×844の実測:

| 負荷 | 高品質FPS | 軽量FPS |
|---|---:|---:|
| 通常プレイ | 13.53 | 18.37 |
| 制御した2,200敵弾 | 17.31 | 29.03 |

描画JS中央値は1.1～1.7ms。更新するGPUバッファを使用分に限定し、不要なMSAA・全面透過HUD・ブレンディングを削減。2,200弾/軽量は最適化前8.02FPS→29.03FPSへ改善したが、この環境では60FPS目標は未達。実機iPhoneの速度を予測できる数値ではない。実機ではまず高品質/軽量の解像度と描画回数を比較し、必要なら背景・粒子・画像アトラスをさらに調整する。

物理iPhone/Android/PC Safari/Edgeでの実機確認、実スピーカーでの音量評価、全2,400装備組合せの人間による遊び心地評価は未確認。初版を「AAA相当」と自動テストだけで断定しない。重い場合はタイトルの設定→描画品質→軽量を利用する。
