# Unity SHOOTING implementation interfaces

World 480×720, origin top-left, y down. Standalone /shooting/index.html. Existing games untouched.

## data.js (content owner)
Exports SHIPS (8), WEAPONS (20), SUPPORTS (15), ITEMS (15), STAGES (5+secret), DIFFICULTIES, ACHIEVEMENTS (~100), ENEMIES (12), PATTERNS (20).
Arrays objects id:number (0-based), name Japanese, description Japanese. SHIPS additionally speed, focusSpeed, hp, hitR, damage, bomb (string), special(string), color(hex number), cost. WEAPONS additionally kind:string (shot,rapid,spread,focus,laser,charge,homing,cluster,plasma,chain,explosive,reflect,drill,wave,saber,absorb,turret,drone,burst,fusion), damage, interval, speed, energy, pierce, range, color, cost. SUPPORTS kind (follow,turret,homing,laser,shield,heal,intercept,collect,bomb,reflect,energy,score,rapid,fusion,secret), cost,color. ITEMS id string P,S,W,L,M,O,B,H,E,G,★,R,X,C,?; weight. STAGES id,name,description,color,color2,midAt:65,bossAt:150,bossName,midName,patternOffset, enemyOffset; 6th secret optional.
DIFFICULTIES object keyed easy,normal,hard,extreme: name,speed,density,hp,rate,reward. ENEMIES id,name,behavior; PATTERNS id,name.

## renderer.js (renderer owner)
export class ShootingRenderer, constructor(canvas,{quality='high',reduced=false}={}), .render(game,alpha=1), .event(e), .resize(), .setQuality(value), .setReduced(bool), .destroy(). Uses existing Three /vendor/three/three.module.js; no CDN/dependency. Worldtop-left. Canvas responsive. Render gracefully title with game=null. Pool instancing for >=2000 bullets. Original detailed ship/boss art via procedural textures; deep green/cyan/ivory/gold sci-fi. distinguish enemy magenta/orange vs ally mint. renderer never mutates game.
