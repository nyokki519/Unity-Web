# 金属製チンチロ・設計と検証順序

2026-10-25。ユーザー指定を実装。追加の設計承認不要という既存指示を維持。本番反映はせず、音付きの一投を完成してから既存CPU戦を検証。

## 仕様

- 皿：真鍮C260相当を想定、密度8530kg/m³（今回メーカー原典確認不可）、直径約278mm、内底半径100mm、内高50mm、法線方向の厚さ4mm。縁は半径2mmの巻いた形、内面サテン・縁磨き・外側やや粗い仕上げ。静的な重い皿として扱う。
- 骰子：16mm中実ステンレス304相当、密度8000kg/m³（設計仮定）、面取り0.8mm、質量は閉メッシュ体積×密度で約32.5g。慣性は凸剛体から算出。深緑の墨入れをした浅い彫り風の目・Unityマーク。
- 刻印は色・バンプ・透明マスクの表面表現。塗料・彫りによる重心や微小凹凸の接触は省略し、均質で対称の物体として扱う。アイコンの画像背景は画素マスクで除去。
- 皿と骰子の接触は同一の共通幾何。法線に沿う外面と丸い縁へ改善する。描画の法線で金属の平面と面取りの区別を保つ。
- 摩擦・反発は未校正の有効係数。金属なので増やすとはしない。重力9.80665、240Hz、CCD、人／CPU共通、出目誘導なしを維持。
- 接触音は独自合成。接触マニフォールドの法線インパルス、接触点速度、角速度から単発・細かい転がり／滑りを作る。空中・静止は無音、休止／リセットは音源停止。同時発音数・音量上限・コンプレッサーを設ける。
- 照明は生成したスタジオ反射環境。外部HDR・音素材を使わない。スマホの負荷を測る。

## 作業順序

1. 体積／質量、滑らかな厚み、マスク、接触データ、音の無音条件のテストを先に作る。
2. 金属モデルと形状、透明な墨入れマップ、皿刻印、反射環境を実装。
3. 法線・接線の物理接触情報を音へ渡し、音OFF／音量・Safariユーザー操作・休止を接続。
4. 皿1個・骰子3個の通常速度／音付き録画を作り、画像・波形・イベント対応を確認。
5. 500投、単独・骰子間・縁、高速CCD、CPU4局、3幅・休止・リセット、既存回帰テスト。公開はせず結果と限界を報告。
