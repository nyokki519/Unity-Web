重いことを理由に重力や落下速度を変えていない。重力9.80665m/s²、240Hz、CCDを維持。静的な皿と同じ重さの骰子同士では質量比が変わらないため、密度を上げただけで必ず遅くなる・長く転がるわけではない。

摩擦は骰子0.28／皿0.32、反発は0.38／0.35を初期の有効係数として保持。金属だから一律に増やす調整はしていない。表面仕上げ・合金・加工状態で変化するため、現物との測定校正は未実施。

## 造形と表示

- 内側の曲面から法線方向へ4mmオフセットして外面を作り、半径2mmの丸い縁でつなぐ。以前の外面のずれ／縁の折れ目を改善。同じ頂点・三角形を衝突にも使用。
- 円周128分割、曲線28分割、縁16分割。皿の描画グループは内面・縁・外面の3つにまとめる。
- 骰子の角を細分化し、平面は平面の法線、丸い辺は丸い法線で反射させる。描画だけを大きな球状にしない。
- 真鍮の内面は微細な同心円状の粗さ、縁は控えめな磨き、外面は落ち着いた粗さ。銀色の骰子は鏡面すぎない仕上げ。
- 明るい天井・縦長のライトを模した独自のスタジオ反射環境を生成。外部HDRや第三者素材なし。
- Unity画像から暗い線画のマスクを取り、紙色を除去。骰子と皿の浅い刻印風に使用。矩形の白いラベルを金属面に貼らない。
- 静止・待機中は再描画を止め、休止・縮小動作・画像読込・ズーム・リサイズ時は必要に応じて描き直す。

## 接触音

`metal-audio.js` に独自の短いモード音と接触ノイズの合成を実装。録音素材や参考サイトの音をコピーしていない。

- Rapierの接触力イベントを読み、接触力×dt、接触点の相対速度（回転成分込み）、接触点位置を音へ渡す。
- 皿への接触は低い基音と金属の短い倍音群、縁では高い倍音成分を強め、骰子同士は短く硬い音へ分ける。
- 面の滑りは接触中の接線速度から短いノイズ片を発音。回転がなくても滑っていれば対象。純粋な転がり・角での接触は衝突音の連なりになる。
- 空中と静止支持荷重では発音しない。同じ組の短時間の接触はまとめ、1フレーム最大4発・同時12音、35msの間引き、ゲイン上限とコンプレッサーで制御。
- 停止時の余韻は短く、休止・OFF・再開始では音源を停止。音量は初期50%、音そのものは初期OFF。最初のON操作でAudioContextを開始。

**音響は実録や有限要素解析による真鍮／鋼の固有振動再現ではない。** 接触に同期する独自合成で、音色・持続時間は調整値。実物と聴き比べた校正は未実施。

## 検証結果

- 全252件のNodeテスト成功。既存レトロ・交流ゲーム6人／15人も含む。
- 閉じた幾何、体積・質量、6面の読み取り、跳ね・骰子間・縁・高速CCD・積み重なり・シード再現を検証。
- 音の検査では、キャッシュされたマニフォールドのインパルスでは一部の衝突を拾えなかったため、実際の接触力イベントに修正。実イベントから音が出ることを回帰テストに追加。
- [500投](../qa/chinchiro-metal/survey-500.json)：有効447、斜め／重なり46、場外7、未停止0。平均確定0.889秒、p95 1.208秒（安定待ち0.45秒込み）。出目の均等性や実物再現度の証明にはしない。
- [ブラウザ3幅](../qa/chinchiro-metal/browser/browser.json)：375／390／414pxで投擲、休止、縮小動作、値の受け渡し、ズーム、はみ出しなし。390pxでCPU4局、精算、再試合、投擲途中の再開始も確認。
- [音の実ブラウザ検査](../qa/chinchiro-metal/audio-browser.json)：初期OFF、ユーザー操作で開始、音量、休止時消音、実接触のPCM、静止後の無音、OFF、紙背景除去、待機時に描画が増えないことを確認。測定した静止後の波形ピーク0。
- [録音レベル](../qa/chinchiro-metal/video/audio-levels.json)：動画のピーク約0.175（-15.2dBFS）、クリップしたサンプル0。これはデジタル音量の検査で、実際の耳元の音圧ではない。
- [非録画の性能](../qa/chinchiro-metal/performance.json)：ソフトウェアGPU・390px・音ON・近景の投擲中で約10.9fps。録画時約10.7fps。**この環境では滑らかさに不足がある。** 実GPUや物理iPhoneの値へ外挿しない。
- 独立レビューで重要な不具合の指摘なし。表示と音の最終的な質感の好み、実機との比較は人の確認が必要。
