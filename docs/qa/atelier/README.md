# 喫茶Unity ATELIER：一段クルーン試作

## 遊び方と起動

`npm ci`（Node24以上）、`npm start`。ホームの「ATELIERを遊ぶ」から別ページ `/atelier/index.html` を開く。既存は「喫茶Unity / レトロパチンコ」で従来の `/?bonus=jackpot` を維持。

20球。投入の強さを選び「一球を送る」。長押しまたはSpaceでも投入可能。同時4球まで。金色の穴100点、銀色10点。ドラッグで回転、ピンチで拡大縮小、視点を戻すボタンあり。音はOFFで開始。タブが隠れたら停止し、再開操作を待つ。玉切れ後に結果と再挑戦。

新モードは**一段クルーンの遊べる試作**。釘盤面・3段構成・次段搬送を含む新しいパチンコ全体の完成版ではない。旧モードには機能変更を加えていない（ホーム表記と共通キャッシュ更新のみ）。

## 技術と調整

- 既存のローカルThree.js、Rapier、earcutを利用。追加サービス・新しい依存関係なし。
- 360mm皿、直径11mm・5.4gの鋼球、直径24mmの3穴。SI単位。
- 皿の三角形メッシュを描画と衝突で共用し、穴には面を張らない。穴の下に排出管と薄い衝突壁。穴から落ちた実位置で結果を決め、入賞後の隠れた抽選や球筋の強制は行わない。
- 衝突面は辺長10mm未満。初期の粗い面からの細分化で不自然な減速が減り、逆に回り続けたため、明示的な線形抵抗0.055/s・角抵抗0.32/sを設定。35秒で解決できない場合は返却を通知し、当たりへ補正しない。
- 固定240Hz、CCD、描画補間。初回/復帰時の負のフレーム時間を遮断。モバイルDPR上限1.75・影1024、玉4球上限。WebGL2不透明コンテキスト・描画保持。
- 陶器・金属・真鍮・外周ガラス、微細な目盛・ネジ、手続き生成のスタジオ反射・金属粒子感。外部モデル、画像、HDRI、音源は追加せず、音も独自の短い合成音。
- 設定: `public/atelier/src/config.js`。形状: `geometry.js`、接触/進行: `physics.js`、描画: `renderer.js`、操作/ライフサイクル: `main.js`、音: `audio.js`。
- 再現: ページ下部のシード番号を指定。シードだけでなく投入の時刻・強さ・順序も一致させる必要がある。

## 検証結果

- Node全テスト196件（新モード5件を含む）。穴が開いていること、最大面サイズ、3穴の落下、同時投入・保存則・二重処理防止・同シード再現・自然落下を検証。
- `node scripts/atelier-survey.mjs`: 通常投入30条件と20球プレイ3回。90球すべて穴で解決、返却0・残存0。単球30条件の平均滞留11.54秒。小標本の当たり数から、校正済みの大当たり確率を主張しない。
- `python test/atelier_browser.py`: Chromium 375/390/414pxで横はみ出しなし、初期20球・音OFF、発射・強さ変更・一時停止/復帰・非表示復帰・結果/再挑戦・実行エラー0。二重pointerdownのタイマー漏れを再現して修正し、1タイマーだけ生成、離すと0になることを検証。読み込み中から非表示の状態でも起動後に停止することを確認。
- 既存レトロ390pxの発射・カメラ・停止復帰の回帰確認に合格。共通キャッシュ更新/オフライン/プレイ中の自動再読み込みなしの既存チェックも合格。
- スクリーンショット `start-375.png` / `start-390.png` / `start-414.png` と各playing画像。
- 独立レビューで見つかった長押しタイマー重複を修正し、再現テストで確認。

## 制限と公開設定

実機iPhone Safari、実機での速度/発熱、60fpsの達成、長時間連続運用は未確認。PCのソフトウェアGPUブラウザの結果をiPhoneの実測とは扱わない。素材は手続き生成と既存ライブラリのみ。権利一覧は `/atelier/NOTICE.txt`。

既存のNodeサーバーで静的配信でき、追加の環境変数やRender設定は不要。mainへのpush後のRenderデプロイ完了はこの環境から未確認。
