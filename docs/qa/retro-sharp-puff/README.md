# r36 最終穴の短い強い噴流

r35の周期送風だけでは、旧版の穴直前で鋭く弾かれる体感が失われていた。周期風は残し、穴へ接近した際の短い圧縮空気の噴流を追加した。

- 最終当たり穴の手前40mm以内に内向きに近づいた際、60msの噴流を始動。穴から外へ広がる方向へ加速度を加える。最大40（既存ゲーム内単位）、有効半径55mm、再作動間隔700ms。球の位置や速度を瞬間的に書き換える旧方式には戻していない。
- 球の位置から空気の方向と強度を計算。正面からなら反転、斜めなら横へそれる。時間方向のsin²分布を積分することで、処理フレーム数による力の違いを抑える。
- 噴流の開始時刻は台全体で共有し、同じ噴流中の近くの球にも作用する。抽選で結果を決めない。送風OFF、他の段、すでに穴へ落下中の球には適用しない。通常の周期風も落下中の球へ適用しないようにした。
- 既存の縁の重力、球同士の衝突、入口、初期200発、カメラは維持。ファン点灯は短い噴流にも同期。

## 検証

- `npm test`: 212件合格。短時間の反転、OFF、落下中の球の保護、他段、遠方、時間刻みの整合性、既存動作を確認。
- Chromium実ブラウザで、周期風の休止中に穴へ向かう速度-0.22の球が100ms後+0.2304へ反転。OFFでは-0.3145のまま穴方向へ進む。作動通知は1回。3段の軌道・実描画位置、球同士の接触、ファンの表示・回転も確認。`contacts-browser.json`、`lip-stage-*.png`。
- 各段200球、最終段はON/OFF各200球の計800球すべて解決。最終段単体ではOFF42/200、ON59/200で当たり。この単体試験では送風が当たりを助ける場合もある。`stage-survey.json`。
- 全経路200発×100回は大当たりあり40回、合計46当たり、20,000発、残留球0、不完走0。r35の52/100から40/100になったが、100回の測定で確定率とは扱わない。`budget.json`。

設定は `public/silver-ring/src/config.js` の `bowls.air`。噴流の式は `bowl-forces.js`、接近検出は `physics.js`。練習モードの最終段投入でも確認可能。

物理は既存の皿面拘束モデル上の近似。実球・流体の完全再現ではない。物理iPhone Safari、本番Renderの反映完了は未確認。識別表示r36。
