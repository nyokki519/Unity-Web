# r34 縁の方向変化のみへの修正

ユーザー指摘の減速・跳ね返りを解消。縁への接触では接触直前の速さを保ち、進む方向だけをわずかに接線方向へ変える。外向き反射、縁摩擦、縁による跳ね上がりは削除した。穴の捕捉範囲に入った球には方向補正を行わず、高速で穴を横切る際の追加減速・中心への引力も現行モードでは無効にした。通常の皿の重力・減衰は継続するため、プレイ中ずっと等速という意味ではない。

球同士の衝突、入口設定、200発の収支、カメラ、停滞時の返球は維持。従来の皿面に拘束したモデルであり、全体の3D剛体実装への置換ではない。基準比較モードの旧挙動は維持。

## 検証

- Nodeテスト205件合格。速さ保存、内向き方向維持、縁による跳ね上がりなし、捕捉範囲内の補正なし、高速通過時の追加制動なしを検証。
- Chromiumの実シミュレーション・描画で3段を確認。接触前(-0.45, 0.18)から接触直後(-0.4362718, 0.2111088)となり、速さは一致。8ステップ後も縁由来の跳ね上がりなし。球同士の軌道変化、返球時の収支、描画位置も確認。結果はcontacts-browser.json、画像はlip-stage-1.png〜3.png。
- 固定発射力0.45、異なるシード100回、各200発の自動プレイ。大当たりあり44回、合計47当たり、発射20,000発、返球0、最終残留球0。小規模の動作確認値であり、当選率の保証・調整ではない。詳細budget-summary.json。
- 物理iPhone SafariおよびRenderの反映完了は未確認。更新識別表示r34。
