## ゲーム

ユーザーの選択どおり、あなた対CPU1人（モカ）。各1,000コイン、親交代で全4局。最大3回、役が出たら確定。出目の1と対戦者の印に、既存の喫茶Unityコミュニティのアイコンを使用。Unity Technologiesのロゴを新規採用したものではない。

順位はピンゾロ、ゾロ目（6〜2）、シゴロ、通常の目（6〜1）、役なし、ヒフミ。同順位は引き分け。勝った役の倍率5／3／2／1で精算し、ヒフミ負けは最低2倍。賭け額を出目前に固定し、両者が最大5倍を払える上限に制限。どちらか5枚未満なら早期終了。

CPUと人間で同じ乱数・判定処理を使用。Web Cryptoの1バイト値を252未満に棄却してから6剰余を取り、一様な1〜6を生成。勝敗・残高・相手の出目による補正はない。転がる表示はCSS演出で、3D物理の結果から出目を決めるものではない。その点はゲーム内ルールに明記。

現金・課金・換金・景品なし。対戦は端末内で完結し、外部AI・有料サービス・サーバールームを利用しない。リロードで対戦リセット。音声は未実装。

## 実装構成と判断

- `public/chinchiro/src/game.js`：役判定、均等乱数、親交代、振り直し、精算、4局進行。
- `public/chinchiro/src/main.js`：CPU進行、操作、モーダル、演出、一時停止。
- `index.html` / `style.css`：深緑・アイボリー・真鍮色の2D卓、木の器と立体風のサイコロ。
- 3D物理の再利用ではなく、軽い独立画面を選択。前のパチンコの描画負荷や精度問題を引き継がず、役と勝負の分かりやすさを優先した実装判断。
- ページ非表示でCPUと演出のタイマーを停止。賭ける前・精算後でも再開可能。ルール／再開始確認中も進行を止める。
- 動きを減らす設定、キーボード操作、見出しに対応したダイアログ名を提供。

## 起動

```sh
npm ci
PORT=3465 DATA_PATH=/tmp/unity-chinchiro.sqlite npm start
# http://localhost:3465/chinchiro/index.html
npm test
python test/chinchiro_browser.py --url http://localhost:3465
```

外部設定や新しい依存ライブラリは不要。本番公開する場合はチンチロのディレクトリとホームの新導線を含める。役物ゲームの配信停止は維持する。
