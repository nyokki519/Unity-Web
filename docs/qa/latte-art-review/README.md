## 操作検証

Chromiumのタッチ入力を用いて、390×844で以下を実行した。

1. タップで点を打ち、タッチドラッグで線を描く。
2. 色・太さを選び、「戻す」で最後の一筆を取り消す。線数が1から0に変わり、Undoが無効化される。
3. 全消しを一度キャンセルして線が残ることを確認後、確定して消す。描き直して画面を横向きにし、戻しても線が残ることを確認。
4. 完成画像をPNGとして保存する。
5. 「編集に戻る」で描画面を再表示する。

保存ファイル `latte-art-export.png` は1024×1280、PNGシグネチャを確認。375px・390px・414px幅で描画／完成画面を確認し、横方向のはみ出しなし。PC相当1280×800でも完成パネルを確認。自動ブラウザ操作ではJavaScriptページ例外なし。

## 修正した不具合

- 完成パネルにHTMLの`hidden`属性が残り、完了後にプレビューが表示されない状態を修正。
- `.draw-controls` / `.pour-controls`のCSS `display`指定がブラウザ標準の`hidden`を上書きし、工程外のコントロールが残る状態を修正。`[hidden]{display:none!important}`を追加。
- 390px幅で説明カードとCTAが重なる配置を分離。
- 注ぎ工程のピッチャーが画面左端で切れていたため、全体が見える位置へ移動し材質を明るく調整。
