# 開放時間比較：各1,000試行

対象コミット7555478の物理。ゲームの追加変更なし。前回48試行を0〜999の1,000シードへ拡張。各条件250発（ファウルは返却）、威力0.45、12発/秒上限、同時30玉、240Hz、最終皿の風0.32、入口妨害OFF。大当たり後も250発完了まで継続するが、主指標は1回以上大当たりした試行数。旧幅へ戻さず、入口幅は両条件とも前回縮小後。

| 指標 | 開放時間変更前 | 開放時間半分（現行） |
|---|---:|---:|
| 試行数 | 1,000 | 1,000 |
| 発射数 | 250,000 | 250,000 |
| 入口通過数 | 50,954 | 34,408 |
| 1球当たり入口通過率 | 20.3816% | 13.7632% |
| 250発で1回以上大当たり | 655 / 1,000 | 537 / 1,000 |
| 同割合 | 65.5% | 53.7% |
| Wilson 95%区間 | 62.50〜68.38% | 50.60〜56.77% |
| 大当たり総数（重複込み） | 1,083 | 757 |
| 終了時残存玉 | 0 | 0 |

250発での大当たり割合は11.8ポイント低下、相対約18.0%減。入口通過数は約32.5%減。同シード対比較の割合差（新−旧）は−11.8ポイント、正規近似95%区間−16.12〜−7.48ポイント。元の条件だけ当たり309試行、変更後だけ当たり191試行。前回48シードの全行が前回結果と完全一致すること、全2,000行に重複がなく、正味250発完了かつ残存玉0であることを検証した。npm test189件成功。

結論: この固定条件では開放時間半減で大当たり頻度は低下。ただし現行も約54%で、目標20〜30%には未達。前回48試行で観測された逆方向の差を今回の結論として維持しない。

限界: 威力固定・シミュレーション上の推定で、実際の全プレイヤーの確率ではない。区間はモデル内の試行ばらつきのみを表す。経路が分岐すると乱数消費も変わるため同シードでも各玉の結果が対応するわけではない。残存玉0は玉詰まりが永久に残らない確認で、物理エンジンの既存救済処理が一度も働かなかったことの証明ではない。
