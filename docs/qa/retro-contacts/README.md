# 喫茶Unity：球同士・穴の縁の接触追加（2026-10-21 JST）

## 変更

球同士や縁との接触による不規則さを、既存の喫茶Unityの3段クルーンへ追加。既存の皿面上の計算に接触モデルを足す方式で、全体をRapierへ差し替えたものではない。

- 球同士の斜め衝突: 皿面の高さと浮き上がりを含めて接触判定。法線方向の反発、接線方向の摩擦で方向と勢いが変化する。高さが離れた球は衝突させない。
- 穴の縁: 実際の穴・リング中心を用い、接触方向と接近速度から反発と摩擦を計算する。失った水平運動エネルギーの一部だけを小さな跳ねへ配分。連続して同じ縁に接触中は繰り返し加速しない。
- 球の跳ねはworldPosへ反映。新しい接触演出ではカメラを揺らさず、球の動きを見せる。既存の接触音を使用し、新規の連続ノイズや音源は追加しない。
- 入賞判定を球同士の衝突後に確定。入賞寸前に他の玉に押された場合、押された後の位置・速度・浮き上がりで判断する。一度落下が確定した後の結果は変更しない。
- 新規の接触計算は乱数・当たりフラグを参照しない。既存の最終皿送風（初期ON）は従来どおり別のルールとして残す。

入口寸法・開放時間、初期4万クレジット/200発、発射単価200、音源、カメラ操作を維持。調整値は `CFG.bowls.contacts`。見えるリング半径と接触モデルの半径を共有する。

## 詰まり対策

接触を追加すると、従来の時間無制限に増える減速で玉が皿の低い所に止まるケースが出た。追加減速の上限を2に設定。さらに、滞留35秒以上かつ低速停止が3秒続いた玉は回収し、1球分のクレジットを返却して画面に通知する。特定の穴へ押し込んだり、当たりを選び直したりしない。

多球の極端な初期重なりで持ち上がる不具合も検出し、重なり解消を皿面上の方向へ限定して修正。衝突による跳ね速度に上限を設け、計算上の爆発や永久浮遊を防ぐ。

- Nodeテスト203件成功。斜め衝突、運動エネルギーを増やさない縁反発、上下に離れた球、完全同位置の球、接触の多重キック防止、跳ねの着地、衝突前の入賞確定防止、3段×12球の有限・一意処理・終了、停止玉の一度だけの返却を検証。
