# 現行r38挙動・風あり/なしの比較

現行main 2846e0f（表示r40、r38挙動）を使用。250発・初期50,000クレジット・1発200。発射力45%、入口割込みOFF、開放時間倍率0.5、240Hz。風だけを変え、同じopening-0〜499のシードで各500回を新たに実行。計1,000回・250,000発。大当たり後も250発すべてを使い切り、すべての球の結果まで待った。

| 指標 | 風あり | 風なし |
|---|---:|---:|
| 250発で1回以上大当たり | 222/500=44.4% | 201/500=40.2% |
| 上記割合の95% Wilson区間 | 40.1〜48.8% | 36.0〜44.6% |
| 大当たり総数 | 284 | 262 |
| 1段目突破 | 5,691/16,835=33.8% | 5,640/16,876=33.4% |
| 2段目突破 | 1,473/5,691=25.9% | 1,443/5,640=25.6% |
| 3段目入賞 | 284/1,473=19.3% | 262/1,443=18.2% |
| 強い噴流作動 | 1,310回 | 0回 |
| 残留球・不完走 | 0 | 0 |

風は3段目だけ。OFFでは周期風と接近時の強い噴流の両方を無効にした。ゲーム本体の既定値や公開中の設定は変更していない。追加したのは測定スクリプトの`--air=on/off/current`指定のみ。

全体の差は風ありが+4.2ポイント。対応するシード間の勝敗差から求めた正規近似95%区間は-1.4〜+9.8ポイント。風ありが必ず有利と断定できる差ではない。風は入賞後に外れへ書き換える処理ではなく、実際の軌道へ力を加えるので、弾かれた後に入り直すなど結果が上向く場合もある。

同じシードから始めているが、風により軌道や球の滞在時間・複数球の接触が変わり、その後の全体進行も変わる。各段への到達数が完全一致する比較ではない。段別割合は全経路でその段へ到達した球を分母とする条件付き割合であり、段へ直接投入した試験ではない。

検証: 各条件500シードの一意性、全試行の正味250発、残留球0、各段の到達=突破+外れ、最終段入賞=大当たり数、風なし噴流0を確認。風あり500回の新しい個票は過去のr38個票と全項目が完全一致し、再現性も確認した。

個票はon/、off/、集計と対応シードの勝敗差はsummary.json。

再現例（開始シード0/100/200/300/400で実行）:

```sh
node scripts/silver-opening-survey.mjs --air=on --seeds=100 --start=0 --shots=250 --scales=0.5 --output=docs/qa/current-wind-comparison/on/seeds-0.json
node scripts/silver-opening-survey.mjs --air=off --seeds=100 --start=0 --shots=250 --scales=0.5 --output=docs/qa/current-wind-comparison/off/seeds-0.json
```
