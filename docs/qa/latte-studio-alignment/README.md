# Latte Studioとの画面比較

2026-11-18〜19の工程Aで撮影した。比較の左は Latte Studio の実操作、中央は Unity MIX の作業開始時の公開版、右はローカルの作業ブランチ。3画面の表示領域はすべて390×844 CSS px。ChromiumのWebGL2をSwiftShaderで稼働させた。新しい比較では、参考側の注ぎパッドでミルクを約110mL入れた合計149mLの一杯を撮った。最大容量と物理端末のGPUでの速度は未確認。 [参考画面](https://lattestudio.pages.dev/play)

## 画面と操作

| 項目 | 観察した差 | この工程での改修 |
| --- | --- | --- |

| 背景と器 | 旧版は赤みが強い木目、青いソーサー、濃い茶色の液面。参考側は落ち着いた木目と白い陶器に左上から光が当たる。 | 木の色を抑え、白いカップとソーサーを別々の断面から生成。丸い縁、持ち手、接地影、泡の縁、チョコの艶を実装。ミルクを注いだ参考画面を見た後、泡を少し下げ、縁から泡へ影が落ちるようにした。 |

Unity MIX版は泡の上を直接なぞる。液面と入力は同じ3D座標を使い、チョコを描く間は水平に保つ。完成画面には画像保存と編集復帰を置く。参考と比べて残る差は卓の微細な木目、陶器の反射とカップの内側の深さ、操作バーの機能、完成画面のボタンの高さ。

## 再開

1. 工程Aの残時間を引き継ぎ、参考側と完成ボタンから写真までのテンポを比べる。繰り返しの操作、古い端末相当の描画、写真を保存した下書きの復帰を確認する。
2. 画面写真を更新するごとに、直接入力、画面回転、保存の取消を再実行する。PCと375px幅で一杯描き切る。
3. 工程Aの実作業120分と品質条件を満たしてから、mainへ反映する。公開URLで工程Bを別枠で60分実施する。

新しい画面は作業ブランチに保存。本番URLでは作業開始時の版が稼働中。

描画中の安定した参考フレームと改修版を同じ座標で重ねた [50%重ね比較](overlay-drawing.png)、工程別の [作業時間の記録](progress.md) も保存した。

追加でLinuxのPlaywright WebKit、iPhone Xプロファイル（375×812）を使用。WebGL表示、タップ、マウスによる連続線、全消しの取消、完成、PNGダウンロード、編集復帰を確認。Chromiumの320×568では下部バーの各ボタン高44px、横・縦スクロールなし、キーボードの完成とスキップを確認した。写真は準備に時間がかかる場合も作品を保持し、完了演出に先に入る。

## 22時台の継続改修

取っ手は上端と下端の二つの付け根、外側へ細くなる断面、斜めの開口を持つ形状にした。陶器の釉薬とスプーンの反射を調整し、木目には周期が途切れない色と細い凹凸を追加した。写真と描画どちらでも、取っ手の開口と液面への非干渉を確認した。

短い320×568の画面では案内の下端を142pxから92pxに移動。390×844の保存ボタンの上端は約348pxから634pxになった。667×375の横画面では写真と操作が横に並ぶ。ハートの先端のような急な折り返しは入力座標を通り、長い作品は描き終えた線を再利用する。書き出し時には毎回同じ順序で合成する。注ぐ練習の泡はピッチャーを動かした側へ広がる。

ローカルのChromiumでWebGLを意図的に失わせ、進行中の線が引きずられないこと、2D表示中にも描いてPNGを保存できること、3D表示へ復帰した後も編集履歴が残ることを確認した。端末固有のGPU停止を再現した実機試験は行っていない。

250本・各48点の線に24回書き足すテストでは、ソフトウェア描画のChromiumでCanvasの2D描画と1画素の読取を含む中央値が約1,827msから34msになった。これは線描画の負荷を比べる合成テストで、実端末のフレーム時間とは異なる。

320〜1280px、DPR 1〜3の5条件で、タップの座標とチョコの点の中心をスクリーンショットから測定した。測った差は最大0.10 CSS px。実測範囲は各画面でカップの中央付近に打った一点。通常の完成演出は約3.01秒、動き軽減は約18ms。演出を省略するタップは、イベントが届いてから結果画面が開くまで約2ms。写真の生成は結果画面を開いてから実行する。

## 描画更新の改修

白い液面と器を3Dで描き、チョコの線は同じ投影行列で液面に重ねた。描画中に3D卓を再描画する処理がなくなり、ソフトウェアWebGLのChromiumで390px・DPR 2のフレーム間隔の中央値は約367msから16.7ms、95パーセンタイルは約417msから33.3msになった（各33フレーム）。320〜1280pxの5条件で、測定点の位置ずれは最大0.05 CSS px。3D写真は直接描画で書き出す。WebKitのiPhone X相当でも描画から画像保存、編集まで確認した。

画像を作っている最中にWebGLを停止させる試験を追加した。正常なPNGと編集への復帰を確認。線が同じ間は完成写真を再利用できる。太さ調整の見本とフォーカスを縦横7条件で確認した。
