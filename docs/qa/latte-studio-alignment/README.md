# Latte Studioとの画面比較

2026-11-18の工程Aで撮影した。比較の左は [Latte Studio](https://lattestudio.pages.dev/play) の実操作、中央は Unity MIX の作業開始時の公開版、右はローカルの作業ブランチ。3画面の表示領域はすべて390×844 CSS px。ChromiumのWebGL2をSwiftShaderで稼働させた。参考側は長いカメラ移動を待つと「ラテアートから」が操作でき、注ぎパッドでミルクを約61mL入れ、合計約100mLでピックと完成へ進んだ。この実操作を最新の比較に使った。満杯時の状態とハードウェアGPUでの速度は未確認。

## 画面と操作

| 項目 | 観察した差 | この工程での改修 |
| --- | --- | --- |
| 描画中の構図 | 旧版のカップは右端で切れ、中心が約420pxの高さにあった。参考側の縁は約280px幅、中央より右寄り、中心は画面上から約290px。 | カップの縁を約285px幅、中心を (225, 300) 前後に調整。ソーサーを大きくし、取っ手を手前へ向けた。 |
| 背景と器 | 旧版は赤みが強い木目、青いソーサー、濃い茶色の液面。参考側は落ち着いた木目と白い陶器に左上から光が当たる。 | 木の色を抑え、白いカップとソーサーを別々の断面から生成。丸い縁、持ち手、接地影、泡の縁、チョコの艶を実装。ミルクを注いだ参考画面を見た後、泡を少し下げ、縁から泡へ影が落ちるようにした。 |
| 描画中の操作 | 旧版の説明、完成ボタン、ペンの列が作品の近くに重なった。参考側は小さな見出しと下端の約246pxの丸いバー。 | 許諾済みの参照UIの配色設定、位置、余白、押下と選択のスタイルを採用。下端に太さ、戻す、全消し、完成を集約し、描き方は短い案内にした。 |
| 完成直後 | 旧版は明るいポストカードを別描画。参考側は暗い全面背景、上に約253px角の写真、右上に閉じる操作。 | 同じ寸法の写真を上に置く全面表示を採用。取っ手を右へ回し、スプーンを添える。画面と同じ3Dモデルから、操作部品の写らない1200×1200 PNGを保存する。 |

Unity MIX版は泡の上を直接なぞる。液面と入力は同じ3D座標を使い、チョコを描く間は水平に保つ。完成画面には画像保存と編集復帰を置く。参考と比べて残る差は卓の微細な木目、陶器の反射とカップの内側の深さ、操作バーの機能、完成画面のボタンの高さ。

ローカルのNodeサーバーで公開環境と同じCSPを使用。タッチエミュレーションで点、ひげ、長い曲線、太さ変更、泡の外への出入り、一筆戻す、全消しの取消、回転、完成、共有中断の模擬、PNG保存、編集復帰を実行した。保存画像とプレビューの画素が一致し、回転・操作復帰後の作品も同一だった。375、390、414px幅と1280px幅で画面幅とボタンを確認した。iPhone Safari実機と、公開版での改修後の操作は未確認。

## 再開

1. 工程Aの残時間を作業時計に引き継ぐ。次は合計約100mLの参考画面を軸に、陶器の反射と内壁の深さを通常の端末でも撮影する。影の境界、取っ手の穴、完成時の画面遷移を同じ座標・時間で再比較する。
2. 画面写真を更新するごとに、直接入力、画面回転、保存の取消を再実行する。PCと375px幅で一杯描き切る。
3. 工程Aの実作業120分と品質条件を満たしてから、mainへ反映する。公開URLで工程Bを別枠で60分実施する。

新しい画面は作業ブランチに保存。本番URLでは作業開始時の版が稼働中。

描画中の安定した参考フレームと改修版を同じ座標で重ねた [50%重ね比較](overlay-drawing.png)、工程別の [作業時間の記録](progress.md) も保存した。

追加でLinuxのPlaywright WebKit、iPhone Xプロファイル（375×812）を使用。WebGL表示、タップ、マウスによる連続線、全消しの取消、完成、PNGダウンロード、編集復帰を確認。Chromiumの320×568では下部バーの各ボタン高44px、横・縦スクロールなし、キーボードの完成とスキップを確認した。写真は準備に時間がかかる場合も作品を保持し、完了演出に先に入る。
