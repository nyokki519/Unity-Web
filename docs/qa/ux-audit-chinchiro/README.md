# チンチロ UI/UX 実操作レビュー

2026-11-08 / 検証対象: `/chinchiro/index.html`（開発サーバー、main f8f1859 相当からの改善）。Chromiumを375×667、390×844、414×896、1440×1000で操作。スマホ幅のブラウザ検証であり、実機iPhone Safari検証ではない。

## 確認した導線と良さ

1. **起動・ベット選択: 良好**。深緑の卓、真鍮の皿、銀色のサイコロ、額面別のコインが統一されている。主要ボタンは375×667でも初期画面内に収まり、横スクロールはなかった。
2. **ルール: 改善を実装**。基本ルールと物理モデルの長文が続き、読む位置によって閉じるボタンが画面外に消える。
3. **投擲・出目確認: 改善を実装**。物理的な投擲は動作。投擲中も主ボタンは「サイコロを振る」の表示で無効になっており、操作の受付状態が文章では分かりにくかった。
4. **一時停止・再開: 良好**。実際の投擲後に両方の操作を確認。
5. **CPU対戦・局結果・最終結果・設定: 良好**。実際の物理投擲で全4局を完走し、4件の履歴、最終残高、音ON/OFF、動きを減らす、再開始確認のキャンセルを操作した。

## 優先順位と実装

| 優先 | 確認済みの問題 | 実装した改善 | 効果 / 工数 |
|---|---|---|---|
| 1 | ルールの長文をスクロールすると閉じる操作が画面外へ移動 | ダイアログ見出し・閉じるボタンをスクロール中も保持 | 戻れないと感じる状況を解消 / 小 |
| 2 | 初心者向けルールと物理実装説明が同じ長さで並ぶ。「ションベン」も役一覧になかった | 物理説明を折りたたみ、場外負けを役一覧へ追加 | 読む量と見落としを減らす / 小 |
| 3 | 人間の投擲中の主ボタン表示が「サイコロを振る」のまま | 「出目を待っています…」と表示 | 受付済み・待機中を明確化 / 小 |
| 4 | ヘッダーのホームリンクは高さ35px、ブランドリンク30px | 両方のタップ領域を44px以上へ | 押し間違いを減らす / 小 |

ゲームルール・コイン精算・物理計算・投擲初期条件・音響処理は変更していない。

## 検証

- `node --test test/chinchiro*.test.js`: 6ファイルすべて通過。
- `python3 test/chinchiro-ux_browser.py`: 上記4画面サイズすべて通過。44pxリンク、スマホ開始ボタン表示、ルールを最下部まで読んだ後の閉じる操作、50枚選択、実物理の投擲、投擲中表示、無効化、一時停止・再開、横あふれ、ページ例外を確認。
- 全4局を実際の物理投擲で完走（約60秒）。最終結果・履歴4件・音ON/OFF・動きを減らす・再開始確認のキャンセルで対戦保持を確認。結果は `full-flow-report.json` に記録。

- iPhone Safariのアドレスバーや実機GPUの影響、スクリーンリーダーによる一連の読み上げは未確認。画面幅だけの検証から問題があるとは断定しない。
