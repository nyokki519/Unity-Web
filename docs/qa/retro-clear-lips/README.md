# r38 全段の縁の軌道変化を強化・初期250発

## 変更

1・2段目の縁による軌道変化が小さいという指摘に対応し、3段共通の落ち込みを3.5mmから8mmへ変更。一方で作用する外半径を43mmから37mmへ狭め、縁の近くでよりはっきり曲がる形状にした。広い範囲を深くする初期案では送風OFFの自然投入30件に3段目の当たりが出ないケースがあり、作用範囲を絞った最終形状で全段の成功・失敗を再検証した。

縁では形状の勾配に沿う重力を積分する。固定角度の跳ね返り、乱数キック、一律の減速は追加していない。物理と皿・球の描画は同じ高さ場を参照する。1・2段目に風は追加せず、3段目の送風設定はr37から維持。入賞時のカメラ振動も無効のまま。

追加指示により1球200クレジット・初期50,000クレジット（250発）へ変更。開始説明・設定表示・再挑戦の表示も5万枚に更新。再挑戦時も250発。

## 検証

- `npm test`: 213件合格。3段の軌道差、中央入球、高速横切り、時間刻み、衝突、入球後の噴流抑止、自然な成功・失敗、250発の収支、旧比較基準を含む。
- Chromium実ブラウザで3段の軌道と球の実描画位置、ファン、強い噴流、球同士の衝突を確認。contacts-browser.jsonとlip-stage-*.png。
- 大当たり、玉切れ、5万枚での再挑戦、再挑戦後の発射数リセット、音ON/OFF、動きを減らす設定を確認。outcomes/内に結果・画像。
- 最終形状・送風ON・発射力45%・入口割込みOFFで250発×500回（125,000発）。大当たりあり222回=44.4%、合計284当たり。返球0、残留球0、不完走0。段別は1段目5,691/16,835=33.8%、2段目1,473/5,691=25.9%、3段目284/1,473=19.3%。summary.jsonとseeds-*.json。
- 500シードの一意性、全試行で正味250発、各段の到達数=突破+外れ、最終段入賞数=大当たり数を検査。

前回r37の200発試験とは発数と形状の両方が違うため、率の差を形状変更だけの効果と解釈しない。

既存の皿面拘束型の近似であり、穴壁との完全な3D剛体接触ではない。実機iPhone Safari、実測フレームレート、Render反映完了は未確認。版表示r38。
