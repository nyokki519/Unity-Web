## 性能・差異

[性能計測](performance.json)はDPR1のChromium SwiftShaderソフトウェアGPU。平均fpsは390pxで高画質5.8→軽量14.9、PC大画面で3.0→9.1。この環境では60fps未達。軽量表示は描画の影と解像度だけを落とし、物理は同じ。物理単体は1万球を上記時間で計算するが、描画負荷と分けて判断する。GPU端末・Safari実機での品質と速度の確認が必要。`python scripts/mechanical-performance.py --url http://127.0.0.1:3461`で再計測可能。
