# r35 穴の縁の重力と最終皿の周期送風

## 原因と修正

r34の縁補正は最大約5度の一度きりの方向変更で、浅い接線接触は速度条件にも遮られていた。送風は削除されていなかったが、球ごとに一度だけの32%抽選だった。

- 縁の速度ベクトル補正を廃止。高さ3.5mm・外周43mm〜捕捉半径19mmの滑らかな落込みを高さ場として定義し、その勾配と重力から連続加速度を求める。複数穴の影響が重なる場所は最も近い穴の表面を使う。一律の減速・外向き反射・乱数キックは使わない。往路で下り、復路で登るため、出入り全体のエネルギーがほぼ保たれる。
- 球の描画高さ、皿のメッシュ、接触時の高さも同じ高さ場を参照。捕捉範囲内では横向きの縁補正をせず、重力下で10mm落下するだけの滞在時間があれば入球。従来の速度閾値による拒否を現行モードでは廃止。高速・浅い横切りは穴から出て旋回を続ける。落下開始時に球が縁へ戻る描画飛びも解消。
- 現行モードの微小な乱数揺らぎは廃止。球同士の衝突は維持し、落下途中の実際の高さも衝突判定に反映。
- 最終皿の送風は1.8秒周期、周期の32%の間に作動する局所噴流。空間・時間の滑らかな強度分布と毎ステップの加速度を使用。穴の奥から皿の中央方向へ吹き、一度作動した球にも次周期では作用する。ON/OFF対応を維持。回転・点灯する小型ファンと既存の噴流演出を同期。
- `chance`は旧比較モードでは確率、現行モードでは運転時間比率。ファンが球を必ず外す保証はないため、UIの「難易度上昇」を「玉の軌道に影響」へ変更した。
- 発射、入口、200発の収支、カメラ、交流ゲーム・CPUは変更していない。歴史的比較モードの基準データも変更していない。

## 検証

- `npm test`: 209件合格。左右対称性、時間刻み240/480Hzの収束、孤立した縁の出入りでのエネルギー回復、遠方・穴内部への余分な力なし、送風の周期・範囲・OFF・再作動、落下と高速通過、衝突後の入球再確認、重複判定・詰まり対策、既存基準を含む。
- 孤立した縁を0.4m/sでかすめる試験では最大11.05度曲がり、退出速度0.400000m/s。これは指定条件の一例で、全接触に同じ角度を付ける実装ではない。詳細 `graze.json`。
- Chromium実描画で3段の軌道、表示高さと実際の球メッシュ位置、球同士の衝突、送風ON/OFFによる速度差、ファンの回転・点灯・非表示を検証。`contacts-browser.json` と `lip-stage-*.png`。
- キャッシュ更新時にプレイ画面を再読み込みしないこと、およびオフラインでも新しい力学モジュールを取得できることを確認。`cache-report.json`。
- 375/390/414pxの既存ブラウザ操作確認を完走。発射、ズーム、停止復帰、横はみ出し、操作領域、JavaScriptエラーを確認。`standard/browser.json` と画像。
- 各段200球、最終段は送風ON/OFF各200球、計800球の自然投入。未解決0。最終段はOFF42/200当たり、ON48/200当たり。送風は33試行で37回球へ作用した。単発抽選で外す方式ではなく、条件次第で当たりへ助けることもある。`stage-survey.json`。
- 200発×100回の全経路シミュレーションでは52回に大当たり、計63当たり、総発射20,000、残留球0、不完走0。物理変更により当選率も変化し得る。100回の観測値を確定当選率とは扱わない。`budget.json`。

## 制約・調整場所

重力は既存ゲームの縮尺に合わせた等価値3.2を維持。既存の皿面拘束モデルに連続的な重力・噴流と落下時間の近似を加えた。実球の回転慣性、3Dの穴の壁やリップとの全接触、実風洞の流体計算まで再現する剛体シミュレーターではない。穴からの次段レール移動は既存の経路アニメーションを維持している。

設定は `public/silver-ring/src/config.js` の `bowls.contacts`（縁・落下）、`bowls.air`（周期・範囲・強さ）。力の式は `bowl-forces.js`。練習モードから各段に投入して確認できる。

実機iPhone Safari、実測60fps、Renderのデプロイ完了は未確認。画面の識別表示はr35。
