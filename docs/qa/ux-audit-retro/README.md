# 喫茶Unity レトロパチンコ UI/UXレビュー

対象: ホームから到達する通常導線 `/?bonus=jackpot` の埋め込みゲームと設定。2026-11-08、現行コードをローカルで実操作。既存の筐体・演出・音・物理・確率は変更していない。

## 確認した導線

1. 開始画面: ルールと「チャレンジ開始」。390pxとPCで開始ボタンは表示され、開始できた。深緑・真鍮色の筐体/操作の一貫性は良い。
2. 単発発射: スライダー、単発ボタン、コイン消費を確認。1球200枚、50,000→49,800枚を維持。
3. 拡大・自由視点: 皿の拡大、自由視点の切り替えと選択状態、元の視点へ戻る操作を確認。直接角度操作を残した。
4. 設定: 表示箇所、威力、動きの軽減、画質、背景演出。以下の改善を実装。
5. 一時停止・再開: 埋め込みヘッダーから操作でき、同じ遊技を継続。

## 単体URLについて

`/silver-ring/index.html` は通常導線のiframe内側であり、直接開くと外側の「Unity MIXへ戻る」「一時停止」「設定」がない。ホームのリンクはシェル付きの `/?bonus=jackpot` に維持した。単体URLへの追加機能は範囲を増やすため実装しない。単体でも非表示時の停止・再開ボタンは存在するが、今回の操作レビューと受け入れテストは通常導線を対象にしている。
