再実行はNode24で `npm ci`、`PORT=3400 npm start`、別ターミナルから上記Pythonチェック。PythonにはPlaywrightとChromiumが必要。動きの重さを優先する場合は画質「省電力（解像度を下げる）」を選べる。

曲面版の回帰：3難易度×60玉で2秒以上の停滞・時間上限回収0件（after-stalls.json）。5シード×100玉の通常発射で全玉決着、計11回の3段突破（natural-flow.json）。練習の独自形状の試行結果であり、実機の確率ではない。

配信の回帰：旧Service WorkerとHTTPキャッシュに旧コードを残した状態から更新し、ページをリロードせず新版を取得、その後オフラインでも新版を取得することを `test/jackpot_cache_update_check.py` で検証。更新時の旧Workerの遅れた書込みで旧キャッシュが再作成される競合も再現し、フォールバックは現行版のキャッシュだけを参照するよう修正。JS/CSSはHTTPで再検証、プリキャッシュも再取得する。プレイ中のページを強制リロードしない。

最終回帰：全148件成功。既存HTTP/WebSocketテストの人物別集計比較は、タグを持たない質問が偶然3問選ばれると両者とも空配列になるため、集計タグのある3問をテスト側で固定した。質問データや本番の抽選処理は変更していない。
