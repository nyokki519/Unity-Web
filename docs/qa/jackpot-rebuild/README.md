# CAFÉ ABYSS — SI-4再設計の検証

LANTERNAの公開コードを取得・ローカル起動して盤面中心の見せ方を観察。ソース・素材のコピーは行っていない。参照記録は[比較資料](../jackpot-lanterna-reference/)。実機の採寸・挙動を再現したものではなく、独自の仮設計。

## 変更

- 道釘・こぼし・寄り・命釘等177本と、途中に落下口を持つ4本の支持路。発射後の横方向の流れを実接触で作る。
- 3段の皿は環状の谷と傾斜を持つ。極座標メッシュ・実開口を描画とRapierで共有し、穴の縁も同じ高さに合わせる。
- 連続したシュートで同じ玉を次段へ移送。隠れた当落抽選、強制誘導、当落を選ぶ映像パターンは使用しない。
- 自動クルーン拡大・全景小窓を維持。オリジナルの筐体、盤面と発射欄を分けた画面、詳細設定の折り畳みを追加。
- SI-3の物理・描画を凍結し、既存記録の再生を維持。上限で拒否された発射の乱数消費も修正。

## 遊び方・起動

Node.js 24以上で`npm ci`、`npm start`。ホームの「おまけ」から開始。強さを調整して単発または長押し発射。皿に入ると自動拡大し、手動視点にも切替可能。音は初期OFF。設定・記録は折り畳み欄へ。登録・ルームは不要。

調整場所：`public/js/abyss/board-routes.js`（釘・支持路）、`tray-layout.js`（皿・穴・摩擦・傾斜）、`si-config.js`（初期玉数・難易度等）。調整後は保存版・再生互換性と自然発射検査を確認すること。

## 制限

物理iPhone/Safari、実端末GPUの滑らかさと音、実機同等性は未確認。Chromiumのスマホ寸法検査と区別する。まれな長期停滞は時間上限回収として明示する安全策を維持。今回の固定シード検査で0件でも、全入力で不発生を保証するものではない。
