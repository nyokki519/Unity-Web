# ションベンの追加

サイコロが1個でも既存の物理場外境界を越えたら、投げた側の即負けとして局を終了する。相手が未投擲でも追加の投擲は行わない。この卓では相手の役によらず賭け枚数の1倍を支払う。人間とCPUで同条件。

斜め停止・重なり・未停止は従来どおり無効投擲で、回数を消費しない。物理形状・投擲条件・場外の境界は変更していない。

検証：親交代前後・先投げと後投げ・役なし後の場外・確定済みの役の変更禁止・二重精算防止を単体テスト。390pxのブラウザでは開始条件を場外へ設定し、実際の物理OUT→人間／CPUの負け表示→精算→次局を確認。出目やOUTの結果の差し替えは行っていない。iPhone実機は未確認。
