# 看板整理・描画リセットの修正

「ひらく門」の飾り看板と、その表示切替処理を撤去。入口機構は維持。左側の表記を「一玉二百枚」へ変更。

resize/visualViewport.resizeのたびに、寸法が同じでもrenderer.setSizeでcanvas.widthを書き換えていた。これは描画バッファを消去する。回帰テストで同寸法の通知を5回送信して書換えが発生することを確認。修正後は幅・高さ・DPRが不変なら作り直さず、表示領域の変更通知は次フレームで描画と一緒に処理する。同一画質の再適用でもDPRを書き直さない。最高画質の設定値は維持。

Node180件成功。Chromiumで不要なリサイズ通知による描画バッファ消去が0回になることを確認。黒いちらつきの全原因を特定したという意味ではなく、実機iPhone Safariで報告された現象そのものは未確認。Render反映完了も未確認。

入力回帰では単発発射3回の間に同寸法通知を送り、消去0回を確認。実寸法変更ではバッファが更新されることも確認した。最高画質のソフトウェアGPUで発射口が空くのを待つ試行は30秒でタイムアウトしたため、リサイズ・入力の検証は省電力設定で分離し、各入力前に物理を240ステップ進めて発射口を空けた。これは実機のフレームレート検証ではない。結果は `docs/qa/resize-flash/resize.json`。
