# 紙幣の省モーション対応と200クレジット調整

紙幣が止まる経路を2つ確認：`banknote-rain.update` が reduced=true でレイヤーを非表示にする処理と、OSのprefers-reduced-motionおよび.reduced共通CSSが `animation:none!important` を全要素へ適用する処理。どちらも修正し、紙幣だけは回転・横揺れなしの36秒直線落下へ変更。明示的な背景演出OFFと一時停止は引き続き有効。

設定に「背景の落下を確認」を追加（全体カメラへ切替・背景演出ON）。更新確認用に「200クレジット・初期6万」と表示。

1球200クレジット、初期60,000＝300球分。通常ルール、威力45%、12球/秒、同時30球、1/240秒、48シードの有限残高シミュレーションで24回突破・24回終了。戻り玉は返金し、発射不能になっても残った玉は決着まで計算。干渉ルールOFF。物理や抽選結果は変更していない。操作条件で結果は変わり、半数の突破を保証するものではない。

測定スクリプト：`scripts/silver-economy-survey.mjs --budget --shots=300`。
結果：`docs/qa/visible-rain-zawa/economy-budget-300.json`。無制限測定と400球検証も同じフォルダに保存。

自動テスト177件成功。Chromiumの390px幅、OS省モーションONで実音源・盤面をロードし、紙幣の可視・移動と発射時200消費を検証。物理iPhoneは未確認。公開URLとGitHubステータスの取得はいずれも接続制限403のため、Render配信バージョンと反映完了は未確認。
