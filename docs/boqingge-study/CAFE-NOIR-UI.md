# Café Noir UI — 2026-10-17

依頼の「基本設計は今のままでよい」を優先し、添付の全面刷新指示から視認性と操作に効く部分を選択した。

採用：深緑にチャコール・シャンパンゴールドを合わせたカフェの素材感、弱い琥珀照明、主要情報だけのHUD、少ない通知、盤面優先の操作、既存Unityマーク、スマホのセーフエリア対応。

今回は行わない：物理モデル・釘配置・穴・抽選条件・コイン計算・音響エンジンの全面交換、他のUnityサービスの変更。「P UNITY」への全面改名はせずユーザー指定の「喫茶Unity」に統一し、Café Noirをデザインテーマとして使う。これにより既存のプレイ感と導線を保つ。

変更：
- 持ちコイン／残弾を小さなHUDにまとめ、発射数・収支などは「プレイ記録」を開いたときに表示。
- 発射威力の標準スライダー、1球発射、自動連射、皿の拡大を下部に集約。傾き・ランダム・補助視点は「その他」にまとめる。キーボードでも操作可能、Escapeで補助操作を閉じる。
- 戻り玉・入口通過・通常外れのトーストを削除。返却コインと内部イベントは保持。その他の案内も積み重なるポップアップをやめ、下部の一行へ置く。通常進行に大きな中央文字を被せない。大当たりは専用表示を維持。
- 背景・金属色・環境反射を落ち着かせ、ブルームを0.55から0.22へ。通常時のピンク照明を弱い琥珀にし、大当たりも金色中心へ統一。
- 手動クルーンカメラは、上部の入口機構で穴を隠しにくい角度へ変更し、手動拡大中だけ入口の装飾看板を非表示にする（入口や玉は消さない）。座標・当たり判定・玉の軌道には影響しない。
- 既存のUnityマークは開始画面で比率を保持して使う。新規のブランドロゴは制作しない。

実装は `public/silver-ring/presentation.css` と `src/presentation.js` に分離。物理本体 `physics.js` と設定 `config.js` は変更しない。Service Workerをv13へ上げ、新しい資産もキャッシュする。

検証：`npm test`、`test/silver_ring_browser.py`、`test/silver_ring_outcomes.py`、キャッシュ更新テスト。ブラウザテストは375／390／414pxと横画面で、単発発射、標準スライダーのキーボード操作、補助操作、記録の開閉、拡大、再接続ではなく一時停止／復帰を確認する。返却／入口イベントを明示的に発行し、返却額が保たれ通知が増えないことも確認（実際の自然発射とは別のUI配線検査）。

`docs/qa/silver-noir/` に変更前後画像と結果を保存する。変更前画像は前回リリースの検証画像から保存。拡大画像のカメラ補間だけはソフトウェア描画のため事前収束させる。iPhone実機、Safari、実GPU60fpsは未確認。
