# 自由視点の上下移動と自動クルーン角度（2026-10-20 JST）

原因: OrbitControlsの平行移動が無効で、panViewも自由視点中は即returnしていた。1本指の回転はできるが、視点の中心を下の皿へ移せなかった。

対応: 既存の2本指上下移動、上下キー、長押しボタンを自由視点でも処理する。カメラと注視点を同じ高さだけ動かし、注視点は0.2〜2.9の範囲に制限。OrbitControls側の無制限パンは引き続き無効にし、左右・奥行きへの平行移動や筐体内への侵入を増やさない。自由視点中にも上下ボタンを表示し「視点を上へ／下へ」と表示する。1本指は回転、2本指は上下移動・ピンチ拡大縮小。

自動クルーン追従: 従来約12度の浅い視線から約30度へ変更。真上にはせず、穴の奥と玉の側面を両方見せる。全3段で共通のカメラ計算を使用。手動の皿拡大・角度調整は従来どおり。

検証: 新しいカメラ位置関数・上下移動関数が存在しない状態でテスト失敗を確認してから実装。npm test191件成功。390px Chromiumで2本指の下移動、下ボタン長押し、上キー、自由視点中のSpace・タップ・発射ボタン、50姿勢での筐体侵入防止、自動追従の実角度（マウス追従込み約28度）を確認。別の描画検証では不透明フレーム、筐体描画、一時停止時の描画保持、コンテキスト消失0を確認。既存の負のフレーム時間対策と不透明描画は維持。

資料: docs/qa/camera-height-r31/。実機iPhone Safari未確認。更新表示「カメラ調整版 r31」。入口・クルーンの抽選、初期200発、突破率には変更なし。
