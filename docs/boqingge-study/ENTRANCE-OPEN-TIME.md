# 入口の開放時間調整（2026-10-19）

目的: 250発中に大当たりする頻度を下げる。既存の入口幅を維持し、羽が開く時間だけを半分にする。

`CFG.shutter.openTimeScale=0.5` を追加。通常開放1.0〜2.4秒→0.5〜1.2秒、短時間開放0.22〜0.65秒→0.11〜0.325秒。閉鎖時間、開閉速度、短時間パターンの混入率、釘、入口幅、クルーン、持ち玉、カメラは維持。短時間パターンは閉鎖側にも使われるため、共用配列を変更せず開放側だけ倍率を適用した。見た目の羽と接触判定は既存の共有角度で更新される。

テスト189件成功。短時間・通常双方について、同じ乱数で開放が半分・閉鎖が不変になることを検証。原作比較フィクスチャには明示的に旧倍率1を設定し、新デフォルトとの比較を混同しない。390px Chromiumで発射・カメラ・一時停止・再開を確認。実機iPhone Safariは未確認。

比較スクリプト: `node scripts/silver-opening-survey.mjs`。変更前後それぞれ同じ48シード、正味250発（ファウル返却あり）、威力0.45、240Hz、風0.32、入口妨害OFF。大当たり後も250発を完了し、少なくとも1回当たった試行の割合を集計。有限試行・固定威力のため一般的な確率や目標20〜30%への到達を保証しない。

実測結果: `docs/qa/entrance-open-time/simulation.json`。本番の反映完了はこの環境から確認できない。更新識別表示は「開放時間調整版 r29」。

結果: 入口通過2381/12000→1701/12000（約28.6%減）。250発中1回以上大当たりは27/48（56.25%）→29/48（60.42%）、大当たり総数40→40。全96試行で正味250発完了・残存玉0。入口通過を減らす効果は観測されたが、大当たり率の低下や20〜30%への到達は確認できなかった。乱数列の消費やクルーン突入タイミングも変わるため、同シードでも同じ玉が対になる比較ではない。
