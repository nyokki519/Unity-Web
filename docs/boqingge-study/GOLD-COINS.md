# 金貨背景・音と説明の整理

画面下の進行説明（routeStatus）を削除。クルーン速度で鳴らし続けていた帯域ノイズの生成・更新を削除。ざわざわ録音、突破音、大当たり音、釘の短い効果音は維持。

紙幣を独自描画の金貨に変更。既存のカップアイコンを刻印風に乗算、表裏を設け、CSSの3軸回転と厚みの影を追加。位置移動と回転を分離し、18〜24秒の低速・加速落下。スローモーションの自由落下風であり、実物の空力計算ではない。筐体外のマスク・操作透過・背景OFF・一時停止を維持。省モーションでは回転なしの36秒落下。

Nodeテスト177件成功。390px Chromiumで落下位置と回転行列の時間変化、進行説明の削除、連続ノイズ生成ノードの不在、発射200消費を確認。旧キャッシュからの更新とオフライン取得も成功。PCエミュレーションであり、実機iPhone・SafariとRender反映は未確認。
