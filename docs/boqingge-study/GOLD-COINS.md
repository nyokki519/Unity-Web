# 金貨背景・音と説明の整理

画面下の進行説明（routeStatus）を削除。クルーン速度で鳴らし続けていた帯域ノイズの生成・更新を削除。ざわざわ録音、突破音、大当たり音、釘の短い効果音は維持。

紙幣を独自描画の金貨に変更。既存のカップアイコンを刻印風に乗算、表裏を設け、CSSの3軸回転と厚みの影を追加。位置移動と回転を分離し、18〜24秒の低速・加速落下。スローモーションの自由落下風であり、実物の空力計算ではない。筐体外のマスク・操作透過・背景OFF・一時停止を維持。省モーションでは回転なしの36秒落下。

Nodeテスト177件成功。390px Chromiumで落下位置と回転行列の時間変化、進行説明の削除、連続ノイズ生成ノードの不在、発射200消費を確認。旧キャッシュからの更新とオフライン取得も成功。PCエミュレーションであり、実機iPhone・SafariとRender反映は未確認。

## 刻印と立体感の再調整
アイコンの写真地を乗算していたため薄い四角が残っていた。`coin-engraving.js` で明るい紙の画素を透明化し、暗い線を金属色の刻印へ変換。背景除去の画素テストを追加。

表裏だけの平面から、24分割の側面（溝付き・厚み6px）を持つ形へ変更。各金貨の回転軸・速度・初期角度を変え、固定軸の角運動と横方向の等速移動を、下方向の加速落下から分離。紙のような往復の揺れを避けた。実物の空力計算そのものではなく、スローな剛体落下を参考にした視覚演出。

テスト178件成功。390px Chromiumで発射・拡大・停止・再開を確認。`test/silver_coin_angles.py` で本番コンポーネントの正面・45度・90度・135度・裏を並べ、矩形地の不在と真横での縁を目視確認した。画像：`docs/qa/solid-coins/angles.png`、ゲーム内：`docs/qa/solid-coins/live-390-844.png`。キャッシュ更新テストも成功。物理iPhone SafariおよびRender反映完了は未確認。
