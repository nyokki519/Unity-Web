# スマホのちらつき・負荷対策

前回の最高画質はスマホでもDPR最大4、HDR後処理バッファの4x MSAA、4096シャドウ、さらに出力canvasのAAを重ねていた。実機で重いとの報告を受け、スマホ用の安定した高精細プロファイルへ変更。

- スマホ：DPR上限2、後処理MSAAなし、出力canvasのAAなし、影1024。異方性16・材質・元の盤面画像は維持。
- PC：従来の最高設定を維持。自動/省電力も残す。発射中にプロファイルが往復する処理は追加していない。
- コイン：側面を24→16面へ減らし、表裏・回転・厚みは維持。背景マスクは整数ピクセルへ丸め、同じ範囲ならclip-pathを再設定しない。

390×644の描画部分・端末DPR3の条件では、1170×1932→780×1288（画素数約56%減）。影の1枚あたり画素数は約94%減。これは描画負荷の設定差であり、実測FPS向上率ではない。MSAA付き浮動小数ターゲットの解決処理と、CSS/WebGL合成の更新負荷を減らす対策であり、実機Safariのちらつきの全原因を特定したという意味ではない。

Node182件成功。スマホ相当DPR3でquality2・DPR2・MSAA0・異方性16、手動画質切替を確認。キャッシュ更新も成功。結果と390pxの操作確認はdocs/qa/mobile-stability/。実機iPhone Safariでのちらつき・FPSおよびRender反映完了は未確認。
