# 筐体外の紙幣と「ざわざわ」音

## 原因と対策
旧演出はCSSで動いていたが、盤面より後ろのレイヤーで、紙幣も小さく暗かった。以前の座標・要素数チェックでは、筐体に遮られる範囲を除外していなかった。

新演出は3D描画から独立したCSSアニメーション。画面上の筐体の投影範囲（全8隅から求めた外接矩形＋8px）を毎フレーム切り抜くため、筐体や抽選皿の上を紙幣が横切らない。固定の左右帯に限定しない。操作を受け取らず、HUDと操作ボタンより下に描画。全体カメラは背景空間を確保するため距離3.88→4.75、皿の拡大機能は維持した。

紙幣は150〜240pxへ拡大、明るさを上げ、既存の喫茶Unityカップアイコンを両端に乗算で印刷。14枚が左右で連続して落下する。一時停止中は停止、設定OFF・動きを減らす設定では非表示。

## 音
ユーザー提供「ざわざわ.mp3」をそのまま収録（約47.7秒）。皿の「ざわざわ…」表示中だけ単一ループを再生し、非表示・ミュートで停止。ランダムな合成ささやきは撤去。初期音声OFFと音量操作を維持。タブ離脱時は既存のAudioContext一時停止に従う。

## 検証
Nodeテスト176件成功。旧レイヤー順で失敗するブラウザ回帰テストを確認後、修正して成功。375/390/414px幅で筐体外の余白と紙幣の可視部分をチェックし、音の表示連動・ミュートを実音源のデコードで確認。人工的に皿へ玉を投入する検証操作を使用（自然到達率の測定ではない）。結果と画像は `../qa/visible-rain-zawa/`。

Chromium/ソフトウェアGPUでの確認であり、実機iPhone Safariと実機での聴感・公開先の反映完了は未確認。

実測：375pxは左右3/3枚、390pxは5/4枚、414pxは4/4枚が筐体外に可視。余白は各側約44/51/63px。紙幣の回転で見かけの横幅は変わる。キャッシュ更新チェックでアイコンURLの重複による登録失敗を検出し、重複を除去した。
