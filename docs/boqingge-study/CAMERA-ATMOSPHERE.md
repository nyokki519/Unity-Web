# 喫茶Unity：カメラ・操作・演出（2026-10-17）

「前の操作性の方がよかった」を受け、ランダム・左右の傾き・体感・自由視点を直接押せる列へ戻した。拡大後は見下ろす／低く見る／左右から見るボタンを表示し、角度を数値表示する。自由視点のドラッグと従来の設定からの各段選択も残す。上下ボタンの長押しとキーボードに対応し、画面を離れたり停止した際には入力を解除する。

## Safari向け配置

以前は親ページの `height:100dvh` と `overflow:hidden` が、iframe下部の操作位置を固定していた。親ページをスクロール可能にし、visualViewportの高さに追従するゲーム領域、最低112pxの下部余白、「操作欄を上に移動」ボタンを設けた。ゲーム内キャンバスだけを操作用に固定し、親ページのスクロールを閉じ込めない。横画面はiframeの最低高さを下げ、開始ボタンを内側でstickyにする。実際のSafariのURLバー表示切替は未確認。

## 演出

- クルーン内の玉と連動した「ざわざわ…」。立体の文字演出も同表記に変更。減動設定では揺れを抑え、3D文字を止める。
- 筐体後方に14枚のオリジナル「UNITY 1000」札が降る。物理の乱数は使わず、コライダーも持たない。表示設定でOFF、減動設定で非表示、一時停止時は更新停止。既存作品の紙幣画像を使用していない。
- 独自の角・コーヒー豆の眼・金属の仮面・翼状の縁取りを紫／紅／真鍮で描いた盤面。添付画像は雰囲気の参考とし、その図柄を埋め込んだりトレースしたものではない。盤面下部のクルーン開口と釘・玉の座標は維持。
- 各段の突破穴の成功イベントで、新しい「ポキューン」系の合成SEを呼ぶ。既存機種の音源・旋律を複製したものではなく、同一音を保証しない。高域の立ち上がり・下降する響き・低音を4声で合成、同時4組に制限し、終了時に音声ノードを切断。音の初期OFFとミュートに従う。
- 「その他」に突破音の試聴ボタン。試聴はコインや当たり判定を変更しない。

## 主なファイル

`public/js/silver-ring/shell.js` と `public/abyss.css` が親のスクロール・高さ・余白を管理する。`camera-pose.js` はカメラの位置と安全な角度範囲、`cabinet-art.js` は独自の盤面、`banknote-rain.js` は背景だけの札、`breakthrough-sound.js` は独自の突破音。`presentation.js` とHTML/CSSが直接操作と状態表示を担当。`physics.js` と `config.js` は変更なし。SW v14へ更新し、新規モジュールを事前キャッシュした。

## 検証

- Chromium：375×568／390×844／414×844／844×390。発射、ランダム、自動連射、拡大、停止・再開、画面退出時の音声解放。ページ例外0。横画面の開始ボタンが画面外に残る問題は再現後に修正し、同じ検査を再実行して成功。
- 390×650の短い画面で親のスクロールを実行。scrollY=62、iframe下端538px、表示高650pxで112pxの余白を確認。Safariの実際のブラウザUIではなく、短い表示領域での配置検査。
- 拡大して左右を10°変更、上下をキーボードで長押しして角度変更。正面からの位置変化と安全範囲を単体テストでも確認。
- 段開始の明示的な投入で「ざわざわ…」を確認。紙幣ON/OFFと減動による停止を確認。
- 3段の成功イベントと外れイベントを明示的に発行し、成功だけ3回のSE呼び出し、コイン不変を確認。これは音の配線検査であり、自然の突破率の検査ではない。
- 新SEをOfflineAudioContextでレンダリング。ピーク0.206、RMS0.0195、ミュートでは生成しないことを確認。サンプルは [original-breakthrough.wav](../qa/kissa-atmosphere/original-breakthrough.wav)。実スピーカーでの聴感・既存実機との音の一致は未確認。
- 既存HTTP/WebSocketテストで一度失敗した比較は、開始前に設定した出題用fixtureが開始時にリセットされることが原因だった。fixtureの設定を最初の出題時に移し、テストのみ修正。サーバーの動作は変更していない。

データ・画像：[docs/qa/kissa-atmosphere](../qa/kissa-atmosphere)。物理iPhone/Safari、実GPUの60fps、長時間の実機試遊、Render反映完了は未確認。
