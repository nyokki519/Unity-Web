# 再開・背景紙幣の修正（2026-10-17）

## 再開

通常のモバイルタップで再開は成功したが、同じ「再開」ボタンのクリックを応答前に2回発行すると停止に戻ることを再現した。従来は `pause` 命令が停止／再開を反転させていた。親からは明示した `setPaused(false)` を送り、同じ再開命令が重なっても停止へ戻らないようにした。旧クライアントのtoggle命令は互換性のため保持。

iframe／Safariツールバー間のフォーカス移動を非表示化と混同しないよう、親ページのblurによる停止を削除し、visibilitychangeで背景移行を判定する。親の再開操作ではiframeへフォーカスする。停止表示内にも「ここから再開」ボタンを設け、子画面の直接のユーザー操作から再開できるようにした。Web Audioの再開拒否はゲーム進行を止めない。

回帰検査はphaseの文字だけでなく、親からの重複再開・子からの直接再開の両方で物理時計が実際に進むことを確認。修正前の重複再開は失敗、修正後は成功。物理iPhone/Safariで報告された現象そのものの再現確認は未完了であり、同一原因と断定しない。

## 紙幣

以前の紙幣は3Dの固定座標に14枚配置され、画面幅やカメラによって左右に切れ、ズーム時には見えなくなる。動きも物理フレームに連動し、描画が重い環境では遅くなる。

紙幣を画面幅に追従する背景の左右各7枚へ変更。WebGL背景を透過し、紙幣レイヤーの上に筐体を描くため、玉・釘・クルーンには重ならない。移動はCSSのtransformアニメーションにし、3D物理の更新速度へ依存させない。停止中はアニメーションも停止し、背景演出OFF／減動設定で非表示。設定変更は停止中でも即時に反映する。
