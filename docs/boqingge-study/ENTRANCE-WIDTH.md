# 入口の幅だけの調整（2026-10-19）

入口の玉中心受付半幅を0.026→0.022、左右羽の支点間幅を0.110→0.096に縮小。入口の輪も追随して縮小。羽の開閉周期、羽の長さ、釘、クルーン、玉数、音、カメラには変更なし。入口は既存の2D中心通過モデルであり、実物の3D開口衝突を新規導入したものではない。

同じ16シード・各250発・威力0.45・240Hz・風0.32・入口妨害OFFで旧幅と比較。旧796/4000発、新782/4000発が入口へ通過。大当たり回数は17→13。全試行で発射完了後の残存玉0。小規模な固定条件での比較で、一般的な突破率の推定ではない。初回の輪・受付幅のみの変更では通過数が変わらなかったため、受け口の左右羽の間隔も縮小した。

再実行: `node scripts/silver-entrance-survey.mjs`。原作参照フィクスチャは旧入口寸法を明示して比較し、新しい寸法の結果と区別している。
