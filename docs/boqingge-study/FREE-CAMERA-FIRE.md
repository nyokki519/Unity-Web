# 自由視点の発射と250発設定

自由視点では `startCharge` が早期returnし、スペースキーによる発射ができなかった。ブラウザ回帰テストで再現してから制限を削除。自由視点のドラッグはカメラ専用のまま、画面タップと発射ボタンは維持。発射口の最小間隔や盤面内の玉数上限による受付拒否は従来どおりで、拒否時は課金しない。

初期50,000クレジット、1発200＝250発分。最終クルーン送風は独立チェックボックスで初期ON（chance=.32）。入口の割込みは初期OFF。過去の300発・送風OFFの突破率測定は、この設定の突破率を示さない。

金貨の3D祖先からopacity<1を除きpreserve-3dを指定。奥行き方向の移動も加え、前後による見かけの大きさが変わる軌道にした。省モーションでも24秒の緩やかな回転を行い、完全な静止板にならないようにした。強い揺れや点滅は追加していない。

検証：Node178件成功。Chromiumタッチ相当で自由視点中のSpace、発射ボタンのタップ、盤面タップを確認。入力方式ごとの検証前にテスト用の玉を除去し、実際の発射口待ち時間が過ぎるのを待った。390pxの省モーション表示で初期50,000と200消費を確認。省モーション時の回転継続・一時停止を別途確認。キャッシュ更新成功。実機iPhone Safari・Render反映完了は未確認。
