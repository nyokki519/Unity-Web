# レトロパチンコ 音声・整数残高・100枚賞球修正

## 原因と対応

### 1. キュインとファンファーレ
前の切出しは2.105–3.350秒で、最後の立ち上がりの一部と余韻を短くしていた。今回は提供元動画の2.035249–3.730秒、1.694762秒を使用。先頭は2ms以内の最もゼロに近いステレオサンプルへ合わせ、PCM16bit/44.1kHzステレオのWAVに格納。追加の非可逆圧縮・音程/速度変更・フェード・無音付加はしない。MP3は過去の試聴URL互換用で、実プレイではWAVを使用。

元音声の操作音は先頭付近、採用部分は後半の効果音区間。波形・スペクトログラムで区間を再検討した。原音と試聴用のファイル区間は `docs/qa/replay-entry-audio/trim-credits1.json` に記録。

`RecordedSounds` は以前から replayEntry と jackpot の別バケットで管理され、相互停止はしていなかった。一方、前版mainは実リプレイがある場合fanfareの開始を省略していた。今回は開始を復元し、キュインとファンファーレの重複再生を明示的に許可。3カット各1回の発音条件は維持する。ミュート・ユーザーによる一時停止は引き続き全音へ適用。

### 2. 1枚表示
内部残高は整数200枚減算で0になるが、表示だけ `S.display += (funds-display)*係数` の小数補間をしていた。UIは前回値との差が1未満で更新を省略し、前回0.9（表示1枚）→実残高0でも表示1枚が残ることをテストで再現（RED）。

小数補間を廃止し、残高の正本を `CoinWallet` へ集約。非負のsafe integerのみ許可し、変更と同時にHUDを更新。UIのキャッシュは表示する整数で比較する。初期/リセット50,000、1発200、200未満発射不可、実発射成功時のみ減算。

### 3. 100枚賞球
現行盤面は「ゲート→導入路→1段目」の構造で、独立した始動口の形状/イベントは存在しない。物理・デザインを維持するため、ゲートを実通過した同じ球が導入路を終えて1段目へ入る地点を始動入賞として採用。この解釈は作業時にもユーザーへ説明した。

ゲート通過ballオブジェクトと賞球済みballをWeakSetで管理。tier0の入賞のみ即時100枚加算。同じballの再通知・ゲート再通知・2/3段目・未通過球/練習投入には加算しない。リセットで両集合を破棄。賞球も残高と同じ整数管理なので次の発射に使える。

賞球で追加発射が可能になるため、以前の「50,000枚勝負=250発」の大当たり率の試算は今の1勝負の確率にそのまま適用できない。賞球なしの250発については正確に0枚。
