# 大皿3Dチンチロ：調査と実装

2026-10-25。本番は既存2D版のまま。この改修は `feature/chinchiro-physical-dice` のローカル実装で、まだ公開していない。

## 調べたもの

1. [3D Dice / Dice Box](https://github.com/3d-dice/dice-box/tree/eea7f1b042338b1083d4d696585b847b84f84a55) のMITライセンス、`physics.worker.js`、`Dice.js`。凸形状、並進と角速度、接触、停止検出、上向きの面の読み取りを確認した。参考先は上向きレイと面IDで判定するが、今回は立方体なので各面法線をワールド座標へ回して上方向との内積で読む独立実装とした。
2. 同梱のRapier 0.21.0公式TypeScript定義：convexMesh、trimesh、CCD、摩擦・反発の合成、慣性・回転、接触マニフォールドを確認。
3. Rapier公式Web、Gaffer固定刻み解説、Dice記事、PMMAメーカーサイトへアクセスを試みたがCONNECT403。[実際のアクセス記録](sources/access.json)。閲覧できたとは扱わず、プロキシ回避や設定変更はしていない。

参照コードの「質量で重力を強くする」「スケールで質量を一次的に増やす」「タイムアウトで質量を0にして強制停止する」処理は採用していない。今回は同じ重力、体積に比例する質量、物理的な停止だけを使う。参照先のソース表現、モデル、画像、音はコピーしていない。

## 物理モデル

| 項目 | 採用値・扱い |
|---|---|
| サイコロ | 一辺16mm、0.8mmの角丸を多面体近似。同じ頂点と三角形を描画・凸剛体に使う |
| 質量 | 体積×暫定密度1180kg/m³＝約4.8g。均質樹脂の仮定で、製品の実測値ではない |
| 皿 | 平底半径100mm、曲がる部分の水平幅35mm、高さ50mm、厚さ4mm。縁上端52mm。特定実物のCADではない |
| 形状精度 | 円周96分割、曲線20分割。表示と接触に同じ閉メッシュを使い、隠れた床・壁・天井はない |
| 更新 | SI単位、重力9.80665m/s²、240Hz、CCD、12回ソルバー、描画の位置・姿勢補間 |
| 接触 | サイコロ間と皿との剛体接触、摩擦、反発、慣性による回転。平均合成で摩擦約0.30・反発約0.365 |
| 抵抗 | 並進減衰0.02、角減衰0.06。接触の摩擦とは別の小さい減衰で、実測の転がり抵抗ではない |
| 初期条件 | 高さ40〜55mm、向こう向き速度0.35〜0.60m/s、横方向最大±0.30m/s、各軸角速度±40rad/s。初期姿勢はSO(3)一様生成 |
| 上面 | 上向き法線との角度30度以内、次点の面との内積差0.2以上。正反対の面は合計7 |
| 停止 | 全3個の速度12mm/s未満・角速度0.6rad/s未満が0.45秒継続してから読む |
| 無効 | 上面が曖昧、サイコロ同士で支え合って重なる、場外、8秒未停止。今回の投擲は回数を消費せず投げ直す |

摩擦・反発・減衰・材質・皿寸法・投げ方は調整可能な設計値で、現物の測定や動画による校正は未実施。乾いた樹脂と皿の静止／動摩擦を別々に測定したモデルではなく、Coulomb接触の有効係数を使っている。

## 出目と表示

出目を先に抽選して停止面へ回す方式は廃止。乱数は初期条件だけに使い、その後の移動・回転・衝突はRapierに任せる。停止後の姿勢を読み、その3値だけを既存の役判定・精算へ渡す。途中の姿勢変更、球筋の誘導、勝敗・残高に応じた補正、タイムアウト後の強制停止はない。

人とCPUは同一の投擲条件を使う。物理モデルの出目が完全に均等だとは断言しない。シードと設定から、同じ実行環境で投擲を再現可能。物理エンジン・ブラウザ・バージョンをまたぐビット一致までは保証しない。

Unityアイコンは1の面に印刷。大皿は俯瞰の3Dで表示し、「近くで見る」で拡大できる。「動きを減らす」では同じ物理計算を行いながら途中の移動表示だけを省き、最終姿勢を表示する。非表示・休止では計算も止める。

## 検証

- [500投の実測ログ](../qa/chinchiro-physics/survey-500.json)：457有効、39斜め／重なり、4場外、未停止タイムアウト0。平均確定0.897秒、p95 1.258秒（0.45秒の安定待ち込み）。
- 接触開始数：床5,029、縁41、サイコロ同士1,552。床と縁の分類は中心半径による概算で、厳密な接触部位別計測ではない。
- 有効投擲の出目1〜6：240／240／213／244／202／232。無効投擲は除外されている。これだけで公平性の証明や実物との一致とはしない。
- 初期条件の高い投げ方では縁で斜めに残る例が多く、停止姿勢を補正せず、平底を広げ、初期投擲を40〜55mmの自然な落下範囲へ修正した。無効な姿勢を有効にするための隠れた力は追加していない。
- 全248件のNodeテスト成功。既存の交流ゲーム6人・15人、レトロ関連も含む。
- 追加検査：シード再現、6面の読み取り、曖昧な角度、閉メッシュ、体積と質量、床での跳ね、サイコロ衝突での軌道反転、高速CCD、曲がった縁、皿の外側の平底での積み重なり無効。
- ブラウザ375／390／414pxで投擲・休止・縮小動作・拡大・値の受け渡しを確認。390pxでCPUとの4局、精算、再試合を確認。[結果](../qa/chinchiro-physics/browser.json)
- 独立レビューで「平底外周の積み重なり」「縮小動作がWebGLへ効かない」を検出。いずれも失敗する検査を作って修正。積み重なりは半径による推測をやめ、接触マニフォールドと上下関係で検出する。
- 実ブラウザ録画中はソフトウェアGPU・DPR1で約31fps、フレーム中央値33.3ms、p95 66.7ms。実機iPhone Safari・実GPUの値ではない。
