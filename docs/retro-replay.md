# 最終入賞の3カットリプレイ

最終当たり穴の実入賞後、入賞通過時刻の0.85秒前～0.22秒後を、正面寄り・左斜め・右斜めの固定カメラから0.33倍速で再生します（各カット末尾0.35秒保持、最大約11秒）。大当たりファンファーレ開始→リプレイ→従来の100万枚払出という順序です。出目・当落・玉の座標を作り替えず、実物理240Hzの位置履歴を線形補間します。

- 対象は最終大当たりのみ。履歴のない検証用大当たりは従来演出へ直接進みます。
- 履歴は最終段の玉だけ、各960点まで。盤面から消えた玉は削除し、再生クリップはコピーして保持します。
- 同じWebGLコンテキスト・盤面・球形状を使用し、録画エンコードや物理再計算は行いません。
- 再生中は全物理と発射を停止。タブ非表示・一時停止では再生時間も停止します。
- スキップボタン／Escで終了。終了・スキップとも視点・球の表示・自由視点設定を復元します。
- 固定視点のカット切り替えのみ。移動ズーム・振動・追加点滅は使用しません。
- 送風OFF初期設定、穴寸法、中央入賞条件、抽選・賞金は変更していません。物理側の変更はsinkイベントへballIdを付加しただけです。

## 最終段専用の入賞粒子・リプレイ音（replay2）
最終当たり穴は従来の汎用粒子を置き換え、穴の中心を避けた64個の金色・アイボリー・ミントの星形粒子と、短い拡張光輪を表示。1・2段目とハズレは従来のまま。物理sinkイベント時刻を原点に、同じ数式で実プレイと各リプレイを描画するため、カットによって粒子の経路や発生位置は変わりません。動きを減らす設定では12粒子・低輝度・光輪なし。

リプレイの各カットで実通過時刻を越えた際に一度だけ、独自の短い合成チャイムを再生。3本の正弦波（最長0.16秒）で、ノイズや長い実録大当たり音の重ね再生は行いません。ミュートを維持し、追加の自動音声許可は不要。実プレイの既存突破音・大当たり録音は維持します。

再生開始時にライブ粒子の時刻を無効化し、終了・スキップ後の再表示を防ぎます。

実入賞からリプレイへ進む際は、sinkWin(2)で開始済みの大当たり録音をfanfare()で重ね直さず、検証用など履歴のない大当たりだけ従来どおりfanfare()を開始します。

replay2検証: Node全285件成功。375/390/414/1280px、3カットすべてで粒子可視・通過チャイム呼出1回を確認。スキップ後の粒子再表示なし、払出は1回。音の波形構成・最長時間・ミュートは単体テストで確認。実機iPhoneでの聴感評価は未確認。結果と画像: `/workspace/Unity-Web/docs/qa/retro-replay2/`。
