# 最終クルーン当たり穴：虹色の縁と落下経路

## 原因と変更
- 最終当たり穴に入った球は、中心から最大19mmのずれを持つ。半径26mmの球に対し旧筒半径は上34mm／下29mmで、端寄りの球が壁からはみ出す寸法だった。
- 旧落下終点は皿基準で64mm下。筒下端44mmに対して球半径26mmの余裕がなく、球が筒の下端を抜ける前にポケット方向の移送が始まっていた。
- 最終筒を半径47mmの直筒に変更。半径＝球26mm＋捕捉中心ずれ19mm＋余裕2mm。上下端を `winFunnelSpec()` に集約し描画へ渡す。
- 捕捉した位置から連続する既存ベジェ移送を維持し、最終落下終点を94mm下へ延長。球全体が筒を抜けてからポケット方向へ移る。これは既存の入賞確定後の移送表現であり、新たな剛体シミュレーションではない。
- 3段目の当たり穴の縁だけに虹色の頂点カラーを付与。毎秒0.8rad（約7.85秒で一周）の色の流れを追加。形状は回転対称で、穴や判定は動かない。「動きを減らす」では色の流れも停止。点滅・拡縮はしない。描画負荷の高い新規エフェクトは追加しない。最終筒出口の余分な金色トーラスは撤去。

## 保護範囲
釘、入賞前の軌道、捕捉半径、送風、持ち玉、突破判定、音源を変更しない。1・2段目の移送点は従来のまま。交流ゲームとチンチロは変更しない。

## 検証
- 捕捉円の縁近く24方向をサンプリングし、各経路201点で球全体が筒半径内に収まること、経路の連続性、筒下端の完全通過を確認。
- 270テスト成功、失敗0。
- Chromium 375／390／414pxで実シーンの描画、虹色頂点カラー、拡縮なし、JSエラーなしを確認。390pxで旧版と修正版の比較画像を保存。
- 実機iPhone Safariは未確認。すべての穴や筒を剛体物理化する改修は含まない。
