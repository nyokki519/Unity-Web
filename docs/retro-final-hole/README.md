# 最終クルーン当たり穴：虹色の縁と落下経路

## 原因と変更
- 最終当たり穴に入った球は、中心から最大19mmのずれを持つ。半径26mmの球に対し旧筒半径は上34mm／下29mmで、端寄りの球が壁からはみ出す寸法だった。
- 旧落下終点は皿基準で64mm下。筒下端44mmに対して球半径26mmの余裕がなく、球が筒の下端を抜ける前にポケット方向の移送が始まっていた。
- 最終筒を半径47mmの直筒に変更。半径＝球26mm＋捕捉中心ずれ19mm＋余裕2mm。上下端を `winFunnelSpec()` に集約し描画へ渡す。
- 捕捉した位置から連続する既存ベジェ移送を維持し、最終落下終点を94mm下へ延長。球全体が筒を抜けてからポケット方向へ移る。これは既存の入賞確定後の移送表現であり、新たな剛体シミュレーションではない。
- 3段目の当たり穴の縁だけに虹色の頂点カラーを付与。約3.33秒で一周する頂点色更新に変更。細い縁の回転では見分けにくかったため、縁の太さを2.8mmから4.5mmへ広げた。形状は回転対称で、穴や判定は動かない。「動きを減らす」では色の流れも停止。点滅・拡縮はしない。描画負荷の高い新規エフェクトは追加しない。最終筒出口の余分な金色トーラスは撤去。さらに当たり穴を囲んで見えていた太い筒の金色材質を反射しない暗い内壁へ変更。

## 保護範囲
釘、入賞前の軌道、捕捉半径、送風、持ち玉、突破判定、音源を変更しない。1・2段目の移送点は従来のまま。交流ゲームとチンチロは変更しない。

## 検証
- 捕捉円の縁近く24方向をサンプリングし、各経路201点で球全体が筒半径内に収まること、経路の連続性、筒下端の完全通過を確認。
- 271テスト成功、失敗0。
- Chromium 375／390／414pxで実シーンの描画、虹色頂点カラー、拡縮なし、JSエラーなしを確認。390pxで旧版と修正版の比較画像を保存。
- 実機iPhone Safariは未確認。すべての穴や筒を剛体物理化する改修は含まない。

## 反映の再確認
前回は細い下端リングだけを除去し、太い金色の筒を残していた。新しい確認はホームからのiframe経由で、通常のRAFだけを動かして連続画像を保存する。色バッファの変化と位置・形状の不変、動きを減らす場合の停止を確認。入口HTML・main・描画モジュールに `rainbow3` の版付きURLを付け、開き直した画面で旧モジュールと混ざることを避ける。既に開かれた画面は自動置換されない。

本番のホーム→iframe→通常RAFで375／390／414pxを確認。輪の画像領域でそれぞれ316／325／297ピクセルの色変化を検出し、連続画像でも確認。最終筒は色0x050b09・金属度0。静止形状、軽減設定での色停止、JSエラー0を確認。画像領域は実際に描かれたマゼンタ部分から抽出する（筐体の独自変換を介した単純な投影では画面外の領域になったため、検証側を修正）。
