# JACKPOT 現行コード監査

対象コミット: `4dd581ea33a879779450404d3c38ec5fb833c848`。監査日: 2026-10-15。今回の添付指示書に照らした再評価であり、実機を観察済みとする記録ではない。実装済みの機能数・既存テスト成功を、新仕様への適合と混同しない。

## 改修対象

入口は `public/js/bonus/screen.js` → `public/js/abyss/screen.js`。物理は `config.js`・`engine.js`・`physics.js`、描画は `renderer.js`。既存ルーム・CPU・他のゲームは対象外。

| 問題 | コード上の根拠 | 影響・再設計対象 |
| --- | --- | --- |
| 発射レールは物理構造ではない | engine.js fire()/update(): launching中は重力と位置積分のみ。renderer.jsのレール描画に対応した衝突形状がない | レール沿いの接触と摩擦を実装し、上部の出口から盤面へ進ませる |
| 発射角でレールを飛び出す | engine.js:167〜195,329〜335。xがboard.right-rを越えると自由運動へ切替 | seed audit、強さ1/55/100はいずれもy約1143〜1155で盤面扱い。上部の釘群y170〜約785より下で自由運動へ移る |
| 強さと角度が実機のハンドルに相当しない | speed=1300+power*7、自由なangle引数 | レール形状で向きを決め、通常は強さ・タイミングを主操作にする。研究用の角度指定を別扱い |
| 釘は役割を持った流路ではない | config.js:15〜29、20行×15列に周期的なsin揺らぎ | 天釘・誘導・入口・アウト等の役割と通過可能な経路を根拠付きで再配置 |
| 寸法と時間の物理単位が未確立 | WIDTH1000/HEIGHT1600/R5.5、g760、ballMassなし | 現在の値をmmと呼び替えない。実寸・推定・描画変換を別定義 |
| 釘の頭と軸が同一の衝突円 | physics.js moveBoard() は p.r+b.r の円 | 釘径10〜12.7に対して球径11。頭部と軸の区別・突出角の近似範囲を定義し直す |
| 皿の寸法・穴数・回転の根拠不足 | config.js:30〜62、径220/180/150、全段3穴、12/-16/20rpm | 原作と実機P沼を混同せず、確認できるまで再現仕様として採用しない |
| 穴が玉に対して大きい | EASY成功穴径/球径=4.4,3.6,3.0。NORMAL=3.344,2.736,2.28 | 実機寸法として誤りと断定はしないが、寸法根拠はなく、写真計測と開口・縁形状の見直しが必要 |
| 皿は実際の3D接触ではない | physics.js moveTray(): x/yばね・粘性・円穴のスイープ | 球の高さ・角運動量・面の法線・穴の縁への接触・鉛直落下を解いていない |
| 穴の横断だけで成功を返す | moveTray() は半径 h.r-b.r の投影円を横切ると即時return | 玉半径は考慮済みだが、滞空・鉛直速度・支持状態がなく、高速で通り過ぎる球の自然な判定にはならない |
| 描画の曲面と加速度が一致しない | engine.js renderZは中心対称放物面、physics.jsはtiltX定数を加算 | 表示した面の低点は中心だが、ばねの平衡点はx=.45R。接触形状と力を同じ3D形状から導く必要がある |
| 次段への進入速度が固定される | engine.js enter(): x=-.88R,y=-.15R,vx=25,vy=-sqrt(spring)*R*.9 | 玉IDは保つが、進入速度・方向を引き継いでいない |
| 移送経路は接触を解かない線形補間 | engine.js transfer()/renderPosition(): .55秒で目標へ補間 | 連続した位置表示でも運動量保存・レールとの接触を満たさない |
| ゲートとの相対速度不足 | engine.js gate判定、impulse()へ移動面の速度を渡していない | 見た目の移動位置と通過幅は共有済みだが、可動部との相互作用を再設計する必要がある |

## 再利用できるもの

- 独立したルーティング、mount/destroy、音声初期OFF、停止・復帰のハンドラー。
- シード・入力記録、JSONの検証、IndexedDB、CSV、Workerの停止／再開。
- 玉数台帳、権利物を使わない素材・合成音、統計の条件付き分母と区間表示。
- 物理と描画の分離、検証記録。ただし新物理へ変更する場合はリプレイのモデル版を区別する必要がある。

## 再現方法

`node tools/audit-jackpot.mjs`。出力は `current-model-audit.json`。モデルを変更せず、寸法比・発射時の盤面切替位置・高速横断の現行判定を取得する。高速横断の例はモデルの構造的な不足を示すもので、実機のその速度での正解を測定したものではない。

## 改修開始条件

今回の依頼は「実機を研究せずに、想像だけで…実装することを禁止」と指定している。指定資料へ接続できない現状では、本格盤面の置換を開始しない。写真・動画・本文の根拠が得られた後、実寸体系→レール→流路→ゲート→3D皿→比較検証へ進める。
