## 実行手順
1. `01_MACHINES/` を読み、P沼・CR天龍∞・トキオ・ファインプレーの機構を比較する。
2. `02_MECHANICS/` と `03_ENGINEERING/` を読み、発射・釘・可動ゲート・3Dクルーンの設計基準を作る。
3. 現在のJACKPOT実装だけを監査する。玉径/穴径、釘配列、発射レール、状態遷移、当落判定、描画の問題を具体的に列挙する。
4. 事実（出典確認済み）・技術近似・推定・ゲーム独自設計を分類する。確認できない実機の寸法は断定しない。
5. `JACKPOT_REDESIGN.md` と `JACKPOT_DIMENSIONS.md` を作成し、変更対象ファイルと段階的実装計画を確定する。
6. 実装する。優先順は発射→釘→ゲート→クルーン3D→物理連携→統計→UI演出。
7. 物理挙動のテスト、寸法比テスト、iPhone Safariを含むUI検証、他のUnity MIXゲームの回帰テストを行う。
8. `JACKPOT_PROGRESS.md` に成果、残課題、検証済み/未検証を記録する。
