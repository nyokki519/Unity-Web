# JACKPOT オフライン役物研究パック v1.0
作成日: 2026-10-15

## 用途
Codex が外部サイトを閲覧できない場合でも、同梱のオリジナル研究ノートを参照して Unity MIX の `?bonus=jackpot` を再設計するための資料。ZIPを展開して `04_CODEX/START_PROMPT.md` をCodexへ渡す。

## 重要な制限
- 公式メーカー資料、写真、動画、記事全文は同梱していない。著作権・取得権限の問題を避けるため。
- 本パックは独自に執筆した技術要約・研究設計・出典URL一覧。実機の分解図、実測寸法、映像フレームの代替にはならない。
- 資料の根拠レベルを区別すること。『未確認』を実機確定仕様に変えないこと。
- 『沼』の漫画版、P沼の実機版、オリジナルゲーム版は別物。
- 現在の公開ゲームの内部コード・実画面は未監査。現状批評はユーザー申告に基づく。

## 読む順番
1. `01_MACHINES/` 機種別ノート
2. `02_MECHANICS/` 発射、釘、役物、クルーン
3. `03_ENGINEERING/` 寸法・物理・検証
4. `05_REFERENCES/` 根拠URLと未確認事項
5. `04_CODEX/START_PROMPT.md` 実装指示

## 根拠が明確な基準値
遊技球：直径11 mm、質量5.4〜5.7 g、鋼製。出典は国家公安委員会規則（別表第四）。ゲーム初期質量は0.0055 kgを推奨するが、機械固有の他の数値は測定せず断定しない。
