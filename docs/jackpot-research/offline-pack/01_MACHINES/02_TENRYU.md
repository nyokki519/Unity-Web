# CR天龍∞／天龍シリーズ
**確認済みの大枠**: CR天龍インフィニティは「天・龍ルート」「三段クルーン」を特徴とする。マルホンの2017年機種ページに記載。
**観察・実装テーマ**: ①役物入口からクルーンまでの導線 ②皿面での球の周回と減衰 ③穴の縁の3D接触 ④成功穴と失敗穴の排出先 ⑤段間の連続的な落下。
**誤解防止**: 球が周回するからといって皿自体が回転しているとは限らない。固定皿か回転皿かは機種・部位別に裏付ける。
**未確認**: 皿径、穴径、摩擦、曲率、個々の穴配置、各機種の細部。
