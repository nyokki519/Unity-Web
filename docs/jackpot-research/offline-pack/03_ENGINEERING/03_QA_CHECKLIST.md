# QAゲート
## 物理
[ ] 発射点からレールへ連続移動
[ ] ハンドルが初速と上部進入位置を変える
[ ] 釘が機能別に配置され、通過可能な経路がある
[ ] 球と釘のすり抜けがない
[ ] ゲート閉鎖時の通過がない
[ ] クルーン穴に実際の幾何学的開口がある
[ ] 成功穴と失敗穴が同じ衝突処理
[ ] 3D皿上で不自然なエネルギー増大がない
[ ] 次段への移動で速度・位置の不連続がない
[ ] 球が無限に停止/周回しない（安全な例外処理）
## 寸法
[ ] 玉径11mm基準
[ ] すべての寸法に出典/推定ラベル
[ ] 釘・入口・穴の玉径比を可視化
## 品質
[ ] 主要ブラウザとiPhone Safari
[ ] 30〜60fps目標（端末条件記録）
[ ] 同一シード・入力で再現可能な条件を記録
[ ] 既存Unity MIXの他ゲームが動作
[ ] 現物動画との比較が可能な箇所は定量比較
[ ] 未検証項目を完成扱いしない
