# SI-2: 詰まり・釘の反発・クルーンの視認性

2026-10-16（日本時間）。公開版SI-1への利用者の報告を再現し、SI-2を分離して改修した。

## 調査と限界

指定されたSANKYOのシミュレーターを再取得したが、通常実行・権限付き実行とも環境プロキシのCONNECT403で拒否。otupyも取得できなかった。今回は実在シミュレーターや動画を直接観察できていない。既存オフライン資料は二次的な技術ノートであり、実機寸法の根拠へ格上げしない。本物と同等の再現度を確認したとは扱わない。

## 再現できた原因

- 釘同士の表面間隔に11mmの玉より狭い箇所があり、入口側のガイドとの組合せも玉を挟んでいた。
- 玉と釘の反発係数が平均され、設定した釘の反発より弱くなっていた。
- 入口の曲がったシュートの側面が折れ、出口も皿の外壁より低く、衝突・停滞していた。
- 成功穴から次段への最初の区間に上りがあり、別の穴の排出路とも交差していた。
- 環状の水平谷が玉の安定した停止位置になっていた。メッシュ密度や摩擦の変更だけでは解消しなかった。
- 穴のカラーが曲面と異なる高さで始まり、段差になっていた。
- 全景では皿が小さく、接近表示でも縦画面の横幅に合わず欠けていた。上段の皿や流路も手前の表示を遮っていた。

## 修正

釘の標準配置で球径より広い通路を確保し、ガイドとの干渉も検査。乱数による玉の操舵は追加していない。釘の接触では指定の反発係数を適用する。初期発射強度は35へ変更。

入口と段間は下りの直線流路に変更し、皿の縁を上から越えて内側で玉を解放する。外れ経路は分離し、穴の下を実際に通過した玉を回収面で回収する。玉を横へ押す、座標を飛ばす、当落を抽選し直す処理はない。

皿は中央の実開口へ向かう円錐面へ作り直し、環状の安定した停止位置を廃止。穴のカラーの始点を曲面の各頂点へ合わせ、下方へ拡げる。練習は中央穴が大きく、通常・高難度は小さい穴を使用する。実機の穴配置と断定しない。

皿ごとの固定俯瞰と縦画面の横幅に合わせた距離計算、上下段を隠す描画断面、明るい金属球、直接操作できる6つの視点ボタンを追加。表示だけを切り替え、衝突世界は変更しない。自動表示は玉の細かな左右移動に追従せず皿全体を映す。減らす設定では自動移動を止め、手動の皿選択は利用できる。

SI-1の設定・物理・描画を凍結して保存し、旧記録をSI-2の別物理で再生しない。設定バックアップも版ごとに分離。
