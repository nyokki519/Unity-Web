# 寸法監査と根拠

これは現行コードの値であり、実機の実測値ではない。単位はlegacy logical unit。玉径11という一致だけで1unit=1mmと決めない。

| 項目 | 現行値 | 根拠 |
| --- | --- | --- |
| 球径 | 11 | config.js BALL_RADIUS=5.5。実機球の約11mmは依頼中の前提 |
| 球質量 | 未定義 | 現行衝突の相対係数のみ。kgへの換算根拠なし |
| 釘の衝突径 | 10〜12.7 | config.js p.r。球径の約0.91〜1.15倍 |
| 最小釘間表面隙間 | 17.8776 | 全300釘の組合せから算出。球径の約1.63倍 |
| 盤面幅／高さ | 1000／1600 | ゲーム独自値。球径の約90.91／145.45倍 |
| 皿径 | 220／180／150 | 前仕様のゲーム独自値。実機寸法の出典なし |
| EASY成功穴径 | 48.4／39.6／33 | 球径の4.4／3.6／3.0倍 |
| NORMAL成功穴径 | 36.784／30.096／25.08 | 球径の3.344／2.736／2.28倍 |
| ABYSS成功穴径 | 26.62／21.78／18.15 | 球径の2.42／1.98／1.65倍 |
| 通常発射の最低間隔 | 0.1秒 | 現行設定。実機発射頻度の資料に基づかない |

写真を取得後、同じ平面内の玉を基準に局所的な穴径・釘径を計測する。傾いた皿の写真は射影・レンズ・遠近を補正し、単純な画像上の円径比を真値としない。動画はfpsと時刻を確認して周回・落下・減速を計測する。

新しい寸法・質量・摩擦係数の採用値はまだ決めていない。メーカー実測、画像推定、材料モデル、ゲーム独自設定をそれぞれ記録してからSIまたは一貫したmm系へ換算する。
