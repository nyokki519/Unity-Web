# SI版の寸法・根拠分類

全物理値をm/s/kgで管理する。描画の1000×1600は物理寸法ではなくpxPerMeter=2000で投影する表示領域。

| 項目 | 初期値 | 分類・出典 |
| --- | --- | --- |
| 球直径 | .011m | オフラインパック03_ENGINEERINGの規格要約。一次URL未直接閲覧 |
| 球質量 | .0055kg | 同規格要約の5.4〜5.7g範囲内の採用値 |
| 重力 | 9.80665m/s² | 標準近似。ゲーム調整値とは分離 |
| 球慣性 | 2/5 mr² | 均質剛体球の近似。エンジンの球コライダーから算出 |
| 盤面表示範囲 | .5×.8m | E：オリジナル仮設計、実機寸法ではない |
| 釘の軸半径 | 約.0015〜.0018m | E：仮設計 |
| 皿直径 | .135/.125/.115mを候補 | E：幾何通過と性能を検証して調整 |
| 穴径 | 球径の1.3〜1.95倍を候補 | E：仮設計。成功穴も失敗穴も同じ接触処理 |
| 皿回転 | 既定0 | E：独自固定皿。実機の回転有無を断定しない |
| 発射間隔 | 通常.6秒を候補 | E：仮設計。研究の高速発射と分離 |

設定ごとのsource/confidence/measuredOrEstimatedをデータに保持する。最終採用値は実装configと検証結果を正とし、実機測定値へ格上げしない。
