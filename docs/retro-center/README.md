# 穴の見た目を維持した中央ヒット判定

ユーザー指定により、穴を大きくする変更を撤回。3段目の黒い開口半径21.5mm、虹色リング中心半径23mm、全5穴の配置半径46mmに戻した。値はゲーム内寸法。

最終当たり穴は別の明示的なゲームルールとして、球中心と穴中心の水平距離5mm未満でのみ落下へ接続する。端寄りでは入賞させず、球を中央へ瞬間移動させない。これは実寸の開口へ球全体を通す剛体物理の条件ではなく、元の意匠を保つ中央ヒットルール。通過後の音、虹色の流れ、下の筒内の移送余裕は維持。

- 全279テスト成功。サイズ・配置の固定、中央4.9mmの受理と6mm／18mmの拒否、入賞通知の一回性・通過後タイミングを確認。
- Chromium375／390／414pxで、元のサイズの縁、中央寄りの落下、端寄りの不成立、JSエラー0を確認。
- 最終段へ直接投入した自然シード200回ずつ：風なし17入賞／183外れ、風あり7入賞／193外れ、未解決0。1勝負250発の大当たり率ではない。
- 中央判定を絞ったため、自然入賞／外れの回帰テストは最終段200シードで両方の成立を確認する。判定基準自体は緩めない。
- 1・2段目、釘、持ち玉、チンチロ、交流ゲームは変更しない。
