# Kobalab 電脳麻将 reference integration

調査対象は公開版「電脳麻将」ver. 2.5.4 と `kobalab/Majiang`。作者の改変・公開許可はユーザーから申告を受け、確認できたMITライセンスの範囲で素材・AIを同梱した。Unity MIXは既存のオンライン対局、点数計算、権威サーバー、スマホ画面を維持する。

## 観察して適用した点

| 観点 | 参照元で確認した良さ | Unity MIXへの適用 |
|---|---|---|
| 牌 | 80×112の鮮明な専用牌絵。萬子・筒子・索子・字牌、赤五、裏面が区別しやすい | 34種・赤五3種・裏面をローカル同梱し、手牌・河・副露・ドラ・伏せ牌に使用。選択・横スクロール・日本語読み上げラベルは維持 |
| 音 | 打牌、チー、ポン、カン、ロン、ツモ、リーチ、効果音をイベントごとに分離 | 対応する局面で個別WAVを再生。初回の明示操作後のみ、音量と同時発音数を抑えて鳴らす |
| ゲーム性 | 手牌の期待値・向聴・受け入れ・危険牌の評価を分けて判断 | Kobalab AIをCPUに接続。出力はUnity MIXの合法手と一致した時だけ採用し、点数・役・勝敗は既存エンジンが決める |
| 操作 | 専用UIは牌操作・局面表示が簡潔 | Unity MIXの4人ルーム、スマホ縦画面、選択牌の説明とアクセシビリティを維持。参考サイトのレイアウトやブランドは移植しない |

## AIアダプターとプライバシー

`src/mahjong/reference-ai.js` はKobalab AIの固定版をCPU判断に使う薄い変換層。渡すのは実行者の手牌・副露、全員の公開済み河・副露、表ドラ、リーチ、点数と残り牌数のみ。相手の手牌、山の牌順、裏ドラ、未公開カンドラは渡さない。Kobalabが選んだ捨て牌／鳴きは、現局面で `legalActions()` が許す手と完全に一致した場合のみUnity側へ返す。変換エラー・不一致では既存CPU判断へフォールバックする。

KobalabのAI/Coreにあるプライベート状態（牌カウントと局モデル）を初期化後に参照している。依存を厳密に1.2.0/1.3.5へ固定し、バージョン更新時はアダプター契約とCPUシミュレーションを再検証する。戦略は参考AIの全機能そのものではなく、打牌期待値と鳴き判断を利用する。勝敗・点数・和了判定はUnity MIXのコードのまま。

## 残る差・未確認

- Kobalabのサイト全体・サウンド演出・レイアウトをUnity MIXに置き換えてはいない。これは4人のリアルタイムルーム機能と現在の縦型スマホUIを保つため。
- 牌を小さく表示する河・副露では、80×112画像を圧縮するため細部は元サイトの卓上寸法と同等にはならない。
- 音量はスマホ向けに調整済みだが、スピーカー／イヤホンの主観評価は実機iPhoneで未確認。
- Kobalab AIはUnity MIXのルール・牌合法性と独立し、合法手の推薦器としてのみ使用する。ラウンド進行、得点、役、罰則まで参照元と同一という意味ではない。
