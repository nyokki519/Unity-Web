# PROJECT ABYSS Implementation Plan

> **For agentic workers:** Use executing-plans for implementation. Independent module owners may work in parallel; integrate against docs/abyss/ARCHITECTURE.md.

**Goal:** 既存交流ゲームを維持し、物理盤面・立体描画・研究／再生が動く独立したおまけを実装する。

**Architecture:** 純粋な固定刻み物理と描画を分離。盤面はJSON、UIは既存DOM、統計はWorker、永続化はIndexedDB。

**Tech Stack:** ES Modules, Three.js, Web Audio, IndexedDB, Node test, Playwright.

**Spec:** docs/abyss/ARCHITECTURE.md とユーザー提供開発指示書。

## Global Constraints

既存ルーム・CPU・別サービスを変更しない。固有意匠を複製しない。実金銭なし。隠れた抽選なし。実行しなかった確認を完了扱いしない。

## Review Focus

- 高速球の釘抜けと可動ゲートの閉鎖時衝突。
- 回転穴と映像の座標が一致すること。
- 保存データの不正値と過大データの拒否。
- タブ切替後の時間飛びと長押し状態の解除。
- 未到達・未決着を確率の分母へ混ぜないこと。

## Tasks

- [ ] 1. engine/configと実動作を検証するテストを作成。高速衝突・台帳・各段・再現性を実行し、物理と設定をコミット。
- [ ] 2. rendererと自己ホスト依存を作成。300釘、動くゲート、回転穴、立体球を描画。WebGLとフォールバックを確認してコミット。
- [ ] 3. analysis/storage/workerを作成。分母とWilson区間、不正保存、シード再生をテスト。近似と物理の結果表示を分ける。
- [ ] 4. screen/audio/CSSを統合。通常・自動・研究・大量試行・再生、設定とエクスポートを動かす。既存mount/destroy契約を維持。
- [ ] 5. 3スマホ幅のブラウザ検証と画像、既存テストを実施。不具合を修正し、PROJECT_STATUSと起動手順を更新。
