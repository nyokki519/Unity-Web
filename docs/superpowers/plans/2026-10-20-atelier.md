# ATELIER Implementation Plan

> Execute inline in this session using superpowers:executing-plans. No subagents; additional design/plan approval waived by user.

**Goal:** A separate playable one-bowl precision prototype, preserving retro play.
**Architecture:** Independent static page; shape mesh shared by Three and Rapier; controller owns lifecycle.
**Tech Stack:** Existing Three.js, Rapier, earcut; Node tests and Chromium Playwright.
**Spec:** docs/superpowers/specs/2026-10-20-atelier-design.md

## Global Constraints
- Preserve retro gameplay and multiplayer; no new external service, library or asset.
- 11mm steel balls, fixed 240Hz, actual three open holes, audio off by default.
- One-bowl prototype scope, explicitly labeled.

## Review Focus
- Genuine hole crossing rather than passing beside/through dish: controlled drop tests.
- Background tab and slow device: capped accumulator and explicit resume tests.
- Multiple simultaneous balls and repeated shot events: cap, ledger, unique resolution tests.
- Small screens: three widths, screenshots, no horizontal overflow or blocked buttons.
- Returning home/retry: dispose physics/GPU state, no retained firing timers.

## Tasks
- [x] Shape and physics (`public/atelier/src/{config,geometry,physics}.js`, `test/atelier.test.js`): first run missing-module tests, implement triangulated bowl with circular apertures, real rigid bodies, fixed stepping, ledger; run seed and controlled outcomes.
- [x] Renderer (`public/atelier/src/renderer.js`): procedural studio reflections, ceramic/metal/glass detailing, ball rotation, orbit and overview camera; inspect screenshots.
- [x] Page lifecycle (`public/atelier/{index.html,style.css}`, `src/{main,audio}.js`): 20-ball session, launch controls, pause/retry, audio off and visibility handling. Verify real UI actions.
- [x] Integration (`public/js/home.js`, `public/sw.js`): separate home links, offline assets and version; preserve retro engine exactly.
- [x] Verification (`test/atelier_browser.py`, docs/qa/atelier): all Node tests, physical run survey, three mobile widths, lifecycle and legacy launch check. Record limitations, commit and push under standing authorization.

Ruling: the final collision mesh uses edges below 10mm (~19k faces) rather than below 7mm (~52k faces); both smaller than the 11mm ball. The denser mesh increased CPU test duration from ~16s to ~36s; final browser/physics runs use the balanced mesh. This is a prototype, not a claim of full real-machine calibration.

Review: fresh reviewer found a multi-pointer hold timer leak; fixed with active-hold guard and lostcapture cancellation. Browser regression asserts two pointerdowns create only one timer and release clears it. Startup hidden state is checked after async engine loading.

Ruling: verification uses 30 standalone power/seed combinations plus three full 20-ball sessions (90 physical ball outcomes), rather than ten full sessions. All final runs complete without returns or unresolved bodies; earlier low-damping configuration failed the natural-drain check and was replaced by explicit rolling resistance. No calibrated hit probability is claimed.
