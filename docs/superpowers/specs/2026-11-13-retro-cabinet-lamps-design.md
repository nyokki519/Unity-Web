# 喫茶Unityレトロ台 外装・ランプ演出 改修設計

## ねらい

既存「喫茶Unity」レトロパチンコを、最初の深緑・真鍮の案に沿って現代的に見せる。画面上の釘盤面、役物、レール、穴、カメラ基準、物理、確率、玉数、操作値、既存演出の意味は維持し、筐体外装の材質・縁の造形・装飾ランプだけを作り込む。

## 対象と対象外

- 対象: `public/silver-ring/src/scene.js` の機体外装、既存 `fx.js` が制御する筐体ランプ、必要な外装専用の表示ロジックと検証。
- 対象外: `boardG` とその子、CFG、物理・入賞判定、カメラ・レイアウト基準値、操作DOM、経済、音声、交流ゲーム、H3独立ゲーム。
- 新規の物理衝突形状、追加外部依存、ゲーム結果に影響するランダム処理は作らない。

## 選んだ方向と実装方式

方向は「深緑塗装・真鍮フレーム・暖色の看板灯・細い緑の側面ライト」を中心とする最初の案。筐体と盤面は現在同じThree.jsシーンにある。CSSの発光オーバーレイは表示角度と自由カメラに追従しないため採らず、物理とは分離した外装専用メッシュを機体グループに加える。既存の役物、盤面テクスチャ、操作台、機能ボタン、画角、基準寸法は流用する。

外周柱の空き部分に、カップの線画を入れた左右対称のエナメル／真鍮メダリオンを加える。看板下のガイド灯は副題に重ならない下縁へ置く。追加形状はすべて `machineG` に属し、当たり判定や `boardG` には加えない。

## ランプ挙動

- 待機: 真鍮と琥珀を中心に、低速で小さく呼吸する。
- 玉が盤面を通過: 入口・皿の実イベントを受け、外周の緑／琥珀セグメントを短く上向きに送る。
- 皿の突破: 次段へ移る瞬間だけ少し明るい琥珀を段階的に流す。
- 大当たり: 強い白金色の予兆と緑・琥珀の短い周回を出し、ゆっくり常灯に戻す。虹色の常時点灯や盤面を隠す光幕は行わない。
- 動きを減らす設定ではチカチカや追従アニメーションを止め、意味のある状態色だけ残す。
- reduced-motion 中は同一色のインスタンス色を再アップロードせず、状態が切り替わったときだけ描画データを更新する。

## 完了基準

- 改修前後で同じ 390×844 / 375×844 / 414×844 の画面を比較できる。
- `boardG` の物理・見た目形状、カメラ基準、発射威力/玉数などのゲーム設定に差分がない。
- ランプの色・軌道が実際の gate / bowl-enter / breakthrough / jackpot イベントに同期する。
- DOM操作の位置、操作ラベル、盤面の見える領域を悪化させない。
- CPU相当のChromium実行で描画エラーがなく、描画コスト増を計測し記録する。
- 既存のレトロ台テストとリポジトリテストを通す。

## 確認済みの前提と制限

- 既存はThree.jsの実機風シーンで、盤面は `boardG`、本体は `machineG` にある。筐体の装飾は表示専用メッシュとして追加できる。
- 提供済みの初案は静止画の方向資料であり、実際の物理寸法の根拠ではない。図の形状を盤面寸法に転写しない。
- Playwright/Chromiumはブラウザ相当検証であり、物理iPhone Safariの実機確認ではない。
