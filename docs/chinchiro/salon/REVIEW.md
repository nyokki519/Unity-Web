# Unity チンチロ — 実画面レビューと改修範囲

2026-10-30。現行ブランチ49ae0a7。390/1440pxの実ブラウザと実投擲を確認。
参照：直前に完成したUnityバカラの素材・情報階層・コイン表現。参考サイト由来の素材やロゴは追加しない。

|項目|観察した問題|対応|
|--|--|--|
|開始画面|見出し・説明・カードが縦に長い。操作が最初の画面外|小さな専用組版、簡潔な上部情報、投擲時の皿へのスクロール。ベット操作は自然な縦スクロールで行う（重なる追従ボタンは不採用）|
|皿|開始時は空。中央の大面積が単調|同じ実メッシュの静的な3個を表示。反射と加工目を整理|
|テーブル|一色のグラデーションで手触りがない|独自フェルト織り、革の縁、真鍮細線、接地影|
|タイトル|汎用明朝のテキストだけ|専用の組版と3つのダイスを用いた刻印風シンボル|
|CPU|あなたと同じアイコンのみで区別が弱い|モカ専用のカップシンボル、YOU/CPUラベル、親表示|
|残高|両者の数値以外に状況が伝わらない|ターンのフォーカス、選択ベットと決着の独立表示|
|賭け|四角い10/25/50/100ボタン|独自Unityコインと積層プレビュー。現行の指定額選択は維持|
|出目|自分の小さい出目と相手の文章しか見えない|両者の3個と役を対比。待ち・投擲中・確定を区別|
|進行|第N局の文章だけ|4局の進行表示、投擲状況チップ、CPUの進行表示|
|役の理解|長いルールダイアログだけ|卓の外の開閉式・役一覧、倍率とションベンを明示|
|決着|文章と残高が即時更新のみ|勝ち/負け/引き分け別の結果、勝者側コイン移動、短い専用音|
|履歴|長い一行の羅列|局・両者の役・純増減を分離した記録|
|設定|下部に操作が散在|音・音量・動きの設定を開閉して整理|
|負荷/アクセシビリティ|既存3Dの良さは維持が必要|静止時再描画停止、音OFF初期、低減設定、44px操作、フォーカス|

## 変えないもの
物理コード、出目の決定、CPUの同条件、4局・1,000枚・最大5倍、ションベン、対戦の再読み込みリセット仕様。他ゲームのコード。
