# レトロ版：クルーンの見通し・材質・構造・接触音

## 実装
1. 3段目の自動カメラを48度の見下ろし・左38度へ変更。拡大視点の初期値も同じ角度にし、ユーザーの角度操作は維持。搬送レールと玉の移送経路は変更しない。
2. 搬送レールを銀色のサテン金属、支持柱・後方アームを暗い金属、皿の縁・入口を抑えた真鍮色に整理。最終穴の虹色と暗い筒を維持。
3. 皿の外周に厚みのある透明樹脂の折り返しを追加。側面の固定座、皿裏に届く支柱、面の傾斜に沿うボルトと座金、後方U字支持枠、既存アームへの連結部を造形。落下口を横切る中央横棒は採用しない。固定金属部は材質ごとに結合描画する。
4. 3段目に生きた玉がある間は環境音を24%、釘音を45%へ抑え、最後の玉がいなくなれば復帰。既存の縁接触・玉同士の衝突・送風イベントから短い異なる接触音を鳴らす。無接触時の架空の連続転がり音や長い雑音は追加しない。ユーザー提供の各段突破音と大当たり音、ざわざわ音源は変更しない。

## 検証
- 全276テスト成功、失敗0。`physics.js`、`config.js`、交流ゲーム、チンチロ、非公開の新作役物ゲームは差分0。
- Chromium375／390／414／1280pxで確認。3段目の穴へ向かう13本の視線の遮蔽は、スマホで6本→0本、PCで5本→0本。拡大初期視点も0本。任意の自由視点まで遮蔽0を保証するものではない。
- 固定部品の連結性、皿面より下に収まることをテスト。移送経路・OUT経路と支持部の432,864組の保守的な包絡ボックス距離チェックで最小12.6mmの余裕。透明縁は独立レビューの経路サンプリングで最低2.90mmの余裕。
- 描画の金具を結合し、同じ390pxの観察で134→103描画呼び出しへ削減。表示品質の完成や実機FPSを意味する値ではない。
- 実WebAudioの接触音ピーク約0.0182、静止後0、ミュート時0。環境音ゲイン0.24→約0.99への復帰、実シミュレーションからの縁・送風・玉接触イベントを確認。
- 本番反映前にレビューで支持座の浮きを指摘され、皿裏への支柱と後方枠で修正。連結性テストの失敗→成功、全テスト成功を確認。

## 限界
実機iPhone Safariは未確認。ソフトウェアGPUによる並行検証中の8秒録画は約2.6fpsで、実機の滑らかさ評価には使用しない。材質はスタイライズした既存筐体に合わせた表現で、実物の測定値ではない。今回は提案1〜4のみで、発射統計や追加モードは実装しない。
