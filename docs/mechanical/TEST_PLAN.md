# 検証計画

現在、新作ゲームのテスト結果は存在しない。以下は実装承認後の計画。

1. 静止釘への正面・接線衝突、薄壁高速CCD、スピン・球同士の衝突を固定初期条件で検証。
2. 羽根・回転体との相対速度、閉鎖中接触、回転掃引を検証。モーターによる仕事をエネルギー誤差と混同しない。
3. 実穴境界のかすめ・落下・逆通過・同時複数球、二重入賞防止と球台帳の保存を確認。
4. 固定シードとtick入力で再実行。描画30/60/120Hzで同じ物理入力の結果を比較。
5. 実映像と同条件の軌跡、通過時刻、滞留時間、位相別到達率を比較。母数と95%信頼区間を併記。未観測の実機率との一致は主張しない。
6. 375/390/414pxのブラウザ、タブ非表示、再開、長押し、リサイズを検証。物理iPhone Safariの性能・操作は別途実機で測定。

可動部がない機種を選ぶ場合、可動接触は校正用治具で検証し、実機に存在しない役物を加えない。
