## 受領と方法

5本すべて取得、映像ストリームの全区間をffmpegでデコードできた。合計約14分07秒、各640×360、符号化フレームレート30fps。最初の4本は180秒ずつ、5本目のコンテナ長は約127.203秒（映像3816フレーム）。撮影元fps、編集速度、原動画との対応、型式銘板は未確認。ファイル名H3だけで型式を独立確認したとはしない。

概観は約10秒ごとの静止フレームを目視。主要区間は約0.1〜0.3秒刻みのフレームと、必要箇所の30fpsフレームを確認した。全14分を等速・音声付きで通して視聴したとは主張しない。全区間のデコード成功は人による全フレーム精査とは別。

各動画の0秒を基準とし、別ファイルの時刻を合算して元動画の時刻とは呼ばない。編集カットや挿入があるため連続実遊技時間や試行母数として数えない。音声は根拠に使用していない。

## 物理設計への含意（まだ実装しない）

自由落下と釘だけでは、保持された球の上向き搬送を説明できない。接触面の運動と保持・離脱条件を分けて調べる必要がある。球を画面上の決められた軌道へ貼り付ける実装にせず、保持力・接触形状の根拠を確保する。磁力が確認された場合は駆動接触だけのモデルでは不足するが、今回の動画から任意の磁力値を設定しない。

V判定を発光や球の不可視化で代用しない。映像で見えない奥の形状と判定面を確認してから仕様にする。バット近傍では球の投影進行方向が変わるため、位相付き可動接触の校正が引き続き重要。
