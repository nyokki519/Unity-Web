# 物理設計（実装前）

- SI単位、標準重力9.80665m/s²。球径11mm・質量5.4gは初期検討値にすぎず、対象機の根拠と許容差を確認する。材質、反発、摩擦、傾斜を校正パラメータとして分離する。
- 保護済みThree.js／Rapier／earcutを再利用候補とし、実装承認時にバージョン・API・ライセンスを固定する。新規有料サービス不要。
- 単一の機構定義から描画と衝突形状を生成する。釘頭、溝、穴の喉部と厚さを含める。描画だけの穴は禁止。
- 固定240Hzは初期候補。球のCCDに加え、回転する可動部の角度掃引と最小特徴寸法を評価し、必要なサブステップを決める。エンジンのCCDだけで回転部の貫通が防げるとは仮定しない。
- 可動部の位置・回転・接触表面速度を物理時刻で更新し描画と共有する。接触相対速度は (v球+ω球×r球)−(v役物+ω役物×r役物)。モーター仕事を含むエネルギー収支を確認する。
- 球スピン、球同士、摩擦、反発を解く。隠れた成功抽選、軌道強制、詰まり解消の瞬間移動は採用しない。異常停止はログで検出し原因を修正する。
- 入賞は球中心・半径・実穴の喉部・通過方向・有効状態で判定し、球IDで一度だけ記録する。ルート間で位置・速度をリセットしない。
- 発射済球=盤面中+役物中+回収済+入賞処理済（互いに排他的）。払出は別台帳とする。
- シード、tick単位入力、物理エンジン版、幾何ハッシュ、初期姿勢を保存。同一固定環境で再現し、Safari等との比較には数値許容差を設ける。

実機固有の寸法・周期・接触材質が未確認のため、現在は設計契約であり完成したモデルではない。

## 直接映像による追加研究項目

中央回転面に沿う球の上向き搬送が観察された。駆動接触に加え、保持／離脱を説明する形状・力の根拠が必要。磁力モデルの採否・値は二次記述だけで決めない。バット近傍の投影軌跡は6点取得したが、世界座標速度・衝突法線・反発係数には換算しない。動画内時間の2.9秒を回転周期に使用しない。
