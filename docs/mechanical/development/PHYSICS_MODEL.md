# 物理モデルと不確かさ

## 単位と数値積分

距離m、時間s、質量kg、力N、角速度rad/s。球半径0.0055m、密度7800kg/m³から `m=4πr³ρ/3=0.0054357kg`、重さ約0.0533N。重力のy成分9.80665m/s²と背面向き0.07倍成分を与える近似（合成は約9.83065m/s²、標準重力より0.24%大）。実盤の傾斜角を校正したモデルではない。

Rapier剛体・摩擦接触で線運動量と角運動量を更新。静的な反発の目安は法線相対速度に対する `v_after=-e*v_before`。固定壁に対して球のエネルギーは摩擦・反発・角減衰で散逸する。一方、モーター駆動の可動部と移動磁極は外部から仕事をするので、球だけの運動エネルギー保存は要求しない。球同士の衝突は剛体ソルバーで解く。

球はCCD有効。外部tick1/240秒。バットの現在・次姿勢から、中心移動＋半対角相当の角掃引距離を計算し、半径の半分以下になるよう最大8サブステップに分割。その他の可動部は同じ物理時刻で進める。描画は前後の剛体位置を補間し、物理の結果を変えない。遅い描画端末は時間を捨てて追いつかせるため、実時間に対して遊技が遅くなる場合がある。

Rapier標準スケールの接触余裕は小球には大きすぎるため、長さ単位1m、許容誤差20µm、予測距離100µm。始動口の判定は共有側壁のクリアランス＋0.3mmのソルバー接触許容を持つ。物理の側壁と比較して中心の判定幅だけ狭くなる問題を実座標から再現し修正した。入賞後は球IDを一度だけ回収。

## 接触材質

球の反発0.42、摩擦0.24、釘0.45/0.12、樹脂0.25/0.22、回転体摩擦0.95。Rapier標準の平均結合則を使用。これらは有効接触パラメータであり、実機の材料測定値ではない。球の角減衰0.08/sは簡略化した転がり抵抗。Hertz接触の変形・音響伝播や摩耗の微視的な解法ではない。

## 回転と磁気の仮説

回転体は横軸のキネマティック剛体、角速度−1.65rad/s。局在する磁極を表面内側に仮定し、物理位置に対する軟化吸引 `F=F0/[1+(d/a)^4]` を磁極方向に加える。`F0=0.20N`, `a=0.018m`、計算範囲42mm、合計力上限0.40N。後方上部の固定遮蔽域では力を0にして搬送先へ解放する。これはMaxwell方程式を解く磁場解析ではなく、観察された上向き搬送を成立させる有効モデル。

参考: 球重力/平均摩擦は約0.09N。近距離の保持力がこれより小さいと持ち上がらない。0.16/0.20/0.28Nの感度試験を別途記録した。大きい力ほどV率が上がるという補正は加えていない。磁石の位置・個数・遮蔽・速度は実機の確認仕様ではない。

## 幾何と経路

`geometry.js`の同じbox/cylinder/sphere/meshをThreeとRapierに渡す。デッキはearcutで穴のある厚み付きメッシュを生成。V/OUTは見える喉部の下方通過と球半径クリアランスで判定する。通過後の隠れた当落抽選はない。

左右の入口から棚へ透明ガイドで接続。左棚の横傾斜は映像で確認した左→右への移動を重力で生む推定。角度は未実測。回転部で捕まらなかった球も通常の重力・衝突でOUTへ進む。永久停止を隠す強制移送・速度付与・球の自動削除はしない。外へ実際に落ちた球のみ回収する。

## 不確かさ

68フレームと6投影点は、寸法・速度・磁力・入賞確率を同定するには不足。透視歪み、遮蔽、編集速度、球の初期条件が不明。理論と接触テストは数値モデルの自己整合性を検証するもので、実機との差の小ささを保証しない。現状の画質も精密CAD/実機写真との同等性は未達。
