# 機能比較と差異

|機能|実映像／資料の根拠|本実装|残る差異|
|---|---|---|---|
|発射・釘|全景で配置の大枠を観察|鋼球剛体、右レール、釘と頭の接触、CCD|釘の位置・盤面角・釘曲げは実測でない|
|始動・羽根|part2 97.0–98.3秒の開閉|物理始動口、独立電子振分、時間開放|0.4/1.3秒等は二次仕様。駆動速度は推定|
|左右経路|資料の左右構成と部分映像|左右の実際の床・壁で分岐|全経路の遮蔽部分は寸法不明|
|ストッパー・揺動棚|研究資料|可動剛体の回転・接触|周期・ストローク推定|
|バット|part3 66.6–67.6秒、球の上向き移動|高速回転接触＋掃引サブステップ|打撃速度・支点は未校正|
|回転搬送|part3 90.8–94.1、part4 33.4–36.4秒|局在磁気保持仮説＋摩擦＋回転剛体|磁石配置・力・遮蔽は未観測のモデル|
|V／OUT|part4隠れた喉部の直視なし、後続表示あり|実穴メッシュと球中心の下向き通過|実機内部の穴・誘導板の形状未確認|
|ラウンド|二次仕様の3/5/10R|Vとは別の電子振分、開始スルー、アタッカー、実入賞14球|252/504/1134をV含むR数−1の9個払いとして暫定採用|
|賞球・収支|二次仕様|始動5球、アタッカー14球、排他的球台帳|一般入賞口4球の機種別配置は未再現|
|音／装飾|原資料は研究専用|独自喫茶・球場意匠、オリジナル合成音|実機装飾・キャラクター・音の複製はしない|
|モバイル|ブラウザ向け独自UI|縦スクロール、パン、ズーム、自動追尾、停止復帰|物理iPhone Safariと実機GPUの60fps未確認|

これは機構をつないだ独立した機能再構成。68フレームと投影6点だけで実機軌道・確率・質感の同等性を証明できない。動画の記録時刻は編集／再生速度不明であり実時間の回転周期に読み替えていない。推定幾何が実機と近いと断言する比較画像も作成していない。
