# 利用素材・権利確認

|対象|出所・扱い|
|---|---|
|ゲームコード|新規独立実装。参考実機ゲームのコードを複製していない|
|盤面／役物／筐体|手続き的な独自幾何。機能研究を反映するが未確認寸法は推定|
|ロゴ／球場図案／表示板|Canvas、Three.jsで独自生成。既存キャラクター・固有ロゴの流用なし|
|効果音|Web Audioで短音を合成。実機録音・第三者曲なし|
|Three.js|既存vendor、MIT。変更なし|
|Rapier|既存vendor、Apache-2.0。変更なし|
|earcut|既存vendor、ISC。変更なし|
|フォント|既存Cormorant Garamond（OFL）とシステム日本語フォント|
|実機映像・抽出静止画|研究専用ローカル資料。ゲームに同梱しない。再配布許諾未確認の画像・動画を今回Gitへ追加しない|
|メーカー・二次機種情報|構造や数値の出典として台帳を保持。メーカー公認や完全実測複製とは表示しない|

H3という型式は研究対象の識別に用いる。商品名・キャラクター・実機装飾・実機音源を商品アセットにしない。原資料の権利者からの素材使用許諾を得たという主張はしていない。
