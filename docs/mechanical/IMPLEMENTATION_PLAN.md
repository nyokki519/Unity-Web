# 開発計画と停止条件

現在Phase 1。ゲーム実装、mainマージ、本番公開は行わない。

1. 原典取得、H3/H1区別、TOKIO・天龍の具体的型式照合。
2. 各候補の主要経路を連続映像で観察し、構造・再現難易度・不足根拠を比較。
3. 推薦機種と誤差・未確認事項をユーザーへ提示し、実装承認を待つ。
4. 承認後に限り public/mechanical/ で共有幾何→発射/釘→主要可動部→V判定を段階実装。既存レトロ・交流ゲームには変更を加えない。
5. 再現可能な物理検証を通し、実機との差異を報告して次フェーズへ進まず停止。

停止条件: 型式混同、連続経路不明、寸法スケールなし、可動部の周期未確認、素材利用条件不明。見た目だけで値を確定しない。
