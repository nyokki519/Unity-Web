# PファインプレーH3 暫定仕様（出典付き）

## 比較的裏付けのある公開情報
- メーカー：マルホン工業。型式：PファインプレーH3。導入開始：2025-10-20（S02/S04/S06）。
- 1チャッカー：通常、羽根約0.4秒×1回。稀なロング開放約1.3秒（S02）。
- 2チャッカー：羽根約0.6秒×2回（S02）。
- 羽根に拾われた玉は左メインルート、右「最強スラッガールート」に振分（S02/S03）。
- メインルート：振分役物→バッター→ローラー→Vを目指す。左右HIT、中央HRゾーンなどが記載（S03）。
- 右ルート：強打者回転体による役物確率約1/3との紹介あり（S02/S05）。試行条件・機械構造は未確認。
- V入賞後は大当たりラウンドを告知し、左スルー通過で大当たり開始、下アタッカーで消化（S02）。
- 賞球5&4&14、3R/5R/10R、設計払出約252/504/1134個（S02/S04）。
- 特図1の内訳：10R-Aロング開放0.4%、10R-B33.2%、5R33.2%、3R33.2%。特図2：10R33.6%、5R33.2%、3R33.2%（S04）。この数値はV入賞率ではない。
- 演出モード：クラシック、実況、先バレ（S02/S08）。

## 実装禁止の推測
- 羽根開閉の厳密な角度曲線・タイミング位相
- 釘の座標・突出角・盤面の傾斜
- バットの動作周期・球との衝突点
- ローラーの回転数、HIT/HR溝形状、V穴寸法
- 左右ルートの分岐確率、実際のV入賞確率
- 払出の個別入賞ごとの細かな実装条件
