# Unity MIX art pass — 2026-10-29

## What changed and why

Baseline screenshots/moving captures showed near-identical beige chips, geometric line-only deck backs/courts, dominant grid felt, repeated ship families, uniform friendly projectiles and single-step explosions. The new direction uses actual dedicated artwork and material layers, not a global glow/quality setting.

**VESPER:** original dark hotel salon background; detailed engraved J/Q/K portraits (three illustrations composed into12suit variants);52exact vector-index cards, one180degree symmetric botanical/guilloche back, paper grain, transparent community heart-cup engraving. Fiber felt, leather rail, brass inlay and six denomination chip faces/edges create material distinctions. Large direct-finger curved-card interaction remains. Shoe-relative glide/rotation/landing, third-card anticipation, moving card reflections and staggered payout flights/landing clicks form the event sequence. Personal loss/push cannot trigger the win climax. A paid TIE has at least medium intensity; returned PLAYER/BANKER stakes do not. No sidebets were introduced.

**SHOOTING:** eight distinct player silhouettes, six hostile families/capital variants, layered original painted stage plates, recognizable weapon shapes and muzzle effects. Armor damage follows actual boss HP/parts. Staged debris/smoke/secondary detonations and a bomb contraction-impact-afterglow provide event hierarchy. Hostile bullets remain above decoration with dark outlines. Player presentation is larger; hitbox unchanged. Independent shake/flash/particle preferences, reduced effects and lightweight modes remain. Result actions stay immediately usable; all delayed visual queues clear across transitions.

Rules, baccarat odds/commission/card order/settlement, shooting DPS1.3/HP/drop rates/rewards and existing game progress are preserved. Only shooting preference defaults/validation were extended (same save format/version). No social/room/retro/chinchiro/backend edits.

Baccarat desktop still has slower-tail frames (latest maximum133.3ms,9long tasks in3rounds); trace shows increased raster work for the richer materials. Moving reflections use composited transforms, static textile has its own layer, expensive redundant per-pixel fiber trigonometry removed. These changes did not eliminate the desktop tail; it remains a known performance limitation, not a solved issue. Mobile-width p95 stayed16.8ms in this sample. Shooting software rendering is approximately20fps even on the baseline, so this environment cannot establish hardware/mobile60fps. Raw evidence: [baccarat measurements](baccarat/qa/art-pass/performance), [shooting matched sample](shooting/qa/art-pass/comparison-performance.json).
