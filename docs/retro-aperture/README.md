# 最終当たり穴の開口と入賞判定の統一

## 原因
ゲーム内の球半径は26mm（直径52mm）だが、旧黒い開口の半径は21.5mm（直径43mm）、虹色の縁の内径は約37mmだった。球より小さい見た目の穴に対して、球中心が穴中心から19mm以内なら一定時間後に入賞する判定があり、端から縁を貫通して入ったように見えていた。

## 修正
- 最終当たり穴の開口半径を32mm（直径64mm）へ変更。虹色の縁の内側・黒い開口・鉛直の筒を同じ位置・寸法に揃え、`hole-geometry.js` に集約。
- 48角形で描画する筒の内接円を考慮し、球中心の許容ずれを `32*cos(π/48)-26 ≈ 5.931mm` に変更。球の中心点だけでなく、球全体が開口に収まる条件にする。
- 最終当たり穴の中心と角度は維持。他の4穴は角度を維持して半径位置を46→65mmへ移し、拡大した虹色の縁と重ならないようにした。支持金具と落下経路の包絡チェックも実施。
- 入り始めの検出は、開口内へ0.5mm下降した時点で既存の移送経路へ連続して接続。球中心を瞬間移動させない。入賞通知・突破音は、球全体が縁の平面を下へ通過するまで保留し、一度だけ発火する。
- 1・2段目の穴位置・開口・判定は維持。送風の設定値、釘、持ち玉、各段の音源、交流ゲーム、チンチロは変更しない。最終段の周辺形状が変わるため、軌道と突破率は以前と同一ではない。

## 検証
- 全279テスト成功。入賞前後の位置の連続性、端寄りの不正入賞を拒否、球全体の通過前に通知しないこと、通知が一度だけであることを確認。
- Chromium375／390／414pxで、実際の開口・縁・筒の寸法一致と、入賞前→落下開始→全通過の画像を確認。18mmずれた例では入賞しない。ブラウザは制御した検証条件。
- 自然シードの最終段投入を送風なし200回／あり200回。なし2入賞・198外れ、あり10入賞・190外れ、未解決0。全入賞の開始時オフセットは5.931mm未満、全通知は球上端が縁の平面以下。これは最終段へ直接投入した結果で、250発の1勝負の大当たり率ではない。少数成功のため風の効果の断定にも使用しない。
- 432,864組の支持部／移送・OUT経路包絡距離チェックで、球半径込みの最小余裕約0.781mm。
- 既存の縁かすめテストは、新しい穴位置に追従し、通過全体を見る200msの観察へ更新。角度差10度以上・旧設定比1.7倍・変位7mm以上の基準は維持。レガシー比較モードも既存テスト成功。
- 独立レビューでCritical／Important指摘なし。

## 限界
これは既存の面上モデル＋入賞後の移送スクリプトを整合させる修正で、穴の周囲を完全な3D剛体衝突へ置換したものではない。実機iPhone Safariは未確認。突破率は変更され得るため、以前の確率推定はそのまま適用できない。
