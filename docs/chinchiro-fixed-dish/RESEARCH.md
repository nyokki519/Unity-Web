# 固定皿と受動的なサイコロ（2026-10-26）

## 今回の訂正

ユーザーの意図は「皿を動かして時間を延ばす」ではなく、固定した皿でサイコロ自体が着地後も跳ね、回転して止まること。以前の規定運動を撤去し、皿をRapierの固定剛体へ変更した。bowl-motion.js、運動設定、描画側の皿の補間も削除。再生速度・重力・結果待ちによって3〜5秒に見せる処理は入れていない。

**3〜5秒は保証できていない。** 固定皿の自然な動きと、毎回一定の時間を維持することを区別する。後者を達成したとは報告しない。実物の同条件の映像や材質測定が未取得なので、このモデルの停止時間を現物の測定結果としても扱わない。

## 根拠と調査

前回取得した[原典・アクセス記録](../chinchiro-tumble/access.json)を再利用した。Rapierの摩擦・反発・減衰の仕様、OpenStaxの並進／回転エネルギー、転がりと滑りの違いを参照。参考ゲームrinblogはアクセス制限により直接操作・録音していない。

追加では、同梱Rapier0.21.0の凸形状・TriMeshFlags・CCD・接触点座標系を確認。固定皿で初速、回転、反発、摩擦、丸い凸形状、CCD有無、予測距離、内側と外側の衝突面、接触法線補正を分けて比較した。これらは数値モデルの感度実験であり、実物の材質係数の測定ではない。

反発を上げるだけ、回転を数倍にするだけでは大きく延びず、場外や斜め停止が増えた。曲面の三角形境界を補正すると不自然な途中停止は減ったが、500投で薄い面を抜ける問題が残ったため、最終版では**接触に三角形メッシュを使わない**。

## サイコロの凸形状と小物の計算条件

丸い角を作る表示メッシュの972三角形中432面は、他の頂点が面の外側へ出る（最大10.37µm）ため、厳密な凸面ではなかった。これを凸であることを前提とするconvexMeshへ渡していた点を訂正した。衝突には同じ頂点のconvexHullを使い、密度から実際の凸包の質量・慣性を計算する。見た目の16mm寸法、1のアイコン、面の向きは維持する。

また16mmの小物をメートル値のまま解く条件では、形状を修正しても稀な支持抜けが残った。計算エンジン内だけをセンチメートルへ単位変換し、設定・描画・検査の入出力はSIのままにした。単位数u=100として、位置／速度／重力はu倍、密度は1/u³倍、慣性はu²倍、接触力／インパルスはu倍になる。時刻、dt、角速度、摩擦、反発は変えない。APIでは位置／速度をuで、慣性をu²で割って戻す。

重力は内部で980.665cm/s²となり、表示の9.80665m/s²と同じ。lengthUnitも100とし、接触許容誤差10µm、予測距離2mmの物理的な大きさを維持した。接触音の位置・力・発音しきい値も同じ単位系へ変換する。長さの単位を変えて転がりを遅くする処理ではない。

メートルとセンチメートルの2条件で、同じ0.1秒の自由落下の位置・速度、質量、慣性が一致する検査を追加。参考の100投ではセンチメートル条件の深い貫通が0件となり、最終500投でも底抜け・金属内部への中心侵入は0件だった。音の観察処理だけを省いた独立の全域検査も同じ500投で一致した。接触剛性・soft CCDの追加変更は比較したが採用していない。

| 皿の材質と運動 | 真鍮の見た目。固定剛体で、手・皿の移動や皿自身の弾性振動は計算しない |

| 慣性 | 均質な凸形状からRapierが計算。約1.378×10^-6kg m²。印・目の微小な凹凸や塗装の質量は省略 |
| 重力／時間刻み | 9.80665m/s²、240Hz。描画の位置・姿勢は物理状態間の補間 |
| 摩擦／反発 | 両方のコライダーを0.18／0.80に設定。局所接触の有効係数の設計仮定で、真鍮と鋼の実測値ではない |
| 空気抵抗 | この短時間・小さな速度では接触損失が支配すると近似し、省略。任意の線形／角速度減衰を0にした |
| 初期条件 | 高さ75〜90mm、横速度0.65〜0.85m/s、直交方向±0.15m/s。初期回転の大きさは手から転がして投げる速度と寸法を基準に与える |

初期姿勢はSO(3)の一様分布。手から離した時点で速度・回転を一度だけ設定し、その後は重力と接触だけ。v/rを使うのは初期回転の尺度に限り、転がっている間に角速度や軌道を強制しない。CPUと人間の条件は同じ。密度が大きいことを理由に落下を遅くする処理もない。

## 厚みのある接触形状

bowlProfile()を描画と衝突の共通断面にした。48の周方向区画×12の曲面区画と48の丸い縁を、厚みのある凸立体へ分ける。625個のコライダー（底1個＋壁576個＋縁48個）が一つの固定剛体に属する。

壁は同じ断面の内側・外側の4点を2つの周方向位置へ回した8頂点の凸立体。縁も同じ半円断面の凸な区画で、内外の金属の厚みを持つ。隣接する部品の境界頂点は一致する。各部品を重心の近くの局所座標で作り、固定皿内へ一度だけ移す。

テストでは壁・縁の全頂点が描画の頂点と0.1µm以内で一致し、壁の6つの面の平面が全頂点を片側に含むことを確認した。したがって凸包で見えていない空間を埋めない。底だけは同じ半径・厚さの解析的円柱で、48角形の描画との半径差は最大約0.107mm。平面の高さは同じ。これは皿全体の数学的な完全一致を主張するものではない。

描画も同じ48／12区画を使う。周囲の輪郭の最大の離散化誤差は約0.29mmで、390px相当では1px未満の尺度。質感・照明は維持し、見た目の違う見えない壁は作らない。

## 物理検査の意味

- 固定皿の位置・姿勢は投擲中ずっと不変。
- 接触がない空中で、追加の力や時間依存の回転操作がない。
- 0.1秒の自由落下でSIの重力による速度・位置を確認。
- 最初の着地後150ms以上経っても上面が切り替わることを確認。
- 並進＋回転＋重力位置エネルギーを追跡し、解放後に外部仕事なしで大きく増えないことを検査。
- 一点接触の球で反発係数を校正。e=0.80に対し実測約0.773（約3.3%差）。多点で当たる骰子全体の重心速度比は、局所接触係数と同じとは限らないため別の検査にした。平面着地の骰子は衝突前より速く跳ね返らないことを検査する。
- 薄い面の試作で抜けたseed25/46/47/97/250/309を回帰検査に保存。
- 最初から静止した骰子は1秒未満で確定。最低3秒／5秒のタイマーはない。
- リロード・休止・再試合・CPUの役と精算は維持する。
