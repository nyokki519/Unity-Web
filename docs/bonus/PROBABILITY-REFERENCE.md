# 提供された確率資料の検証

出典はユーザーがチャットに貼り付けたシミュレーションの要約。リンク先の本文・動画・台の寸法を直接確認した記録ではない。実装済みゲームの実測確率を示すものでもない。

## モデルの前提

各通過を独立と仮定すると、釘 1/100 × 羽 1/5 × 皿 1/3 × 1/4 × 1/5 = 1/30,000。羽の値は仮定であり、釘を 1/1 とした別説明なら結果は 1/300 になる。両者を混同しない。

1発4,000円は資料の換算値であり、ゲームへの課金や換金の導入を意味しない。

## 理論値

累積成功率は `1 - (1 - 1/30000)^n`。

| 資料の換算額 | 発数 | 累積成功率 |
| --- | ---: | ---: |
| 300万円 | 750 | 2.469% |
| 4,000万円 | 10,000 | 28.347% |
| 1億2,000万円 | 30,000 | 63.213% |
| 3億円 | 75,000 | 91.792% |
| 4億円 | 100,000 | 96.433% |

上限なしの初当たり平均は30,000発。未当選の試行も100,000発として集計する打ち切り平均は約28,929.84発となる。「平均約28,000発」は集計方法・試行数なしでは同じ指標と断定できない。成功した試行だけの平均とも区別する。

## 実装への適用上の区別

- 100発では累積成功率は約0.333%。短時間の練習・通常プレイに、この確率を無説明で適用しない。
- 穴が3・4・5個あるだけでは通過率が1/3・1/4・1/5になるとは限らない。寸法、入口、速度、傾斜によって偏るため、物理モデルでは実測が必要。
- 資料は確率の参考であり、釘の衝突係数、皿の形状、球の旋回・落下時間を裏付けない。映像を確認したと扱わない。
- 物理的に穴へ入った結果と表示を一致させる。確率を合わせるために落下後の当否を変更しない。
