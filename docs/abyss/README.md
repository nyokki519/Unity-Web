# PROJECT ABYSS

Unity MIXのおまけを、300本の釘・周期ゲート・3段の回転皿を持つ独立した1人用ゲームへ更新。オリジナルの名称・筐体・合成音で構成し、実金銭は扱いません。

## 起動

Node.js 24以上。

```sh
npm ci --ignore-scripts
npm start
```

起動後、ホームの「大穴チャレンジで遊ぶ」、または `/?bonus=jackpot` を開きます。Three.jsの配信ファイルは同梱済み。再生成は `npm run vendor:three`。外部CDN、APIキー、追加の有料サービスは不要です。

## 遊び方

EASYから開始し、強さ・角度を調整して「1球発射」または長押し。100玉を使い、入口→可動ゲート→3段の金色の穴を目指します。暗い穴は回収口。3段突破は10,000点です。すべての玉が決着すると結果になり、途中終了・再挑戦もできます。

- NORMAL：手動発射。Spaceで発射、左右キーで強さ、Pで一時停止。
- AUTO：発射間隔と追加発射数を指定。実際の同じ盤面で玉を動かします。
- LAB：重力・反発・摩擦・釘の位置・ゲート・回転速度・穴サイズを設定。適用で新しいセッションになります。各段の縁・成功穴・回収穴からの確認も可能。検証操作を含む記録を通常リプレイとして保存することはできません。
- MONTE CARLO：独立確率による近似と、固定刻みの実物理試行を別表示。1,000〜1,000,000回を選択し、中断・再開・中止できます。実物理は独立した1球ずつの試行で、連続発射時の玉同士の干渉を含む率とは異なります。
- REPLAY：保存した履歴やJSONを読み込み、シードと発射入力から再計算。再生・停止・速度変更・1コマ送り。入力を処理できない／結果が一致しない記録はエラーを表示します。

皿に進んだ玉は既定で最深段を自動追跡します。カメラ・表示欄で全体表示・追跡、拡大、盤面の指操作、4種類のヒートマップ、軌跡を切り替えられます。音は初期OFF。端末設定に合わせた動きの軽減も可能です。画面を離れるとプレイと研究を停止し、自動で再開はしません。

## 設定と記録

既定の機構は `public/js/abyss/config.js`。発射、衝突、皿の運動は `engine.js` と `physics.js`。盤面設定はLABでも変更できます。300本の円形釘は位置を編集します。円の回転角は衝突形状を変えないため、角度調整として偽の機能は表示しません。

設定・プリセット・通常プレイ履歴・研究結果はIndexedDB内の `abyss` に保存します。履歴などは種類ごとに100件まで。サーバーへ送信しません。保存できない環境では画面へ失敗を表示し、JSON/CSV出力を使用できます。ブラウザのデータ削除で記録も消えます。インポートは5MBまで、スキーマ・範囲・発射間隔・台帳の整合性を検証します。

## 物理モデルの範囲

固定240Hz。高速球にはスイープ判定、球同士には相対スイープと接触解決を使用。反発・接線摩擦・スピンを扱います。ゲートは実際の遮断位置と描画を共有。皿は傾斜力・回転面との相対速度・減衰を持つ専用モデルです。移送路は状態遷移で扱い、完全な3D剛体・空気力学の実機再現ではありません。

穴は回転後の位置を物理・描画で共有し、球全体が落下口へ収まる位置で落下します。隠れた当落抽選・当たりへ曲げる補正はありません。40秒を超えて停滞した球や計算異常は明示した回収処理を行います。皿の20%／15%／10%という仕様書の目標通過率は未較正で、保証値として表示していません。参考資料の1/30,000も実物理の当選率ではありません。

区間推定はWilson 95%。独立二項試行を仮定した目安であり、玉同士が干渉する連続セッションで厳密な信頼区間と見なさないでください。進行中・標本不足・時間上限による未決着を区別します。成功0件を真の確率0と断定しません。
