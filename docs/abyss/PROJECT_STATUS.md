## 制約・未確認

- 皿は専用の傾斜・回転モデル。実機の3D剛体計測を再現したものではない。資料の実機・動画との画質や物理精度の比較は未実施。
- 20%／15%／10%の段別目標突破率は未較正。実測条件を添えず保証値にしない。
- 円形釘の角度編集は意味がないため位置編集に置換。ピンチは「盤面を指で拡大・移動する」で有効化し、通常のページスクロールと切り替える。
- 大量試行の実物理は独立1球ずつで、連射時の相互作用を含む率ではない。物理100万回の完走は未実施。
- SwiftShaderでは約4〜6fps。ハードウェアGPUでのPC60fps／スマホ30〜60fpsは未確認。物理iPhone Safari、タッチ実機、発熱・GPUメモリ測定も未確認。
- ヘッドレスのOSタブ切替がvisibilitychangeを再現しないため、blur／visibilityハンドラーの確認と実機バックグラウンド復帰は区別する。
- デバッグ投入・玉数変更の記録は通常リプレイに保存しない。CSV統計は出力可能。
