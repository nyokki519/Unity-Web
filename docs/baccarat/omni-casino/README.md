# 全方向の絞りとカジノ卓の調整 — 2026-10-30

ユーザーの指定した2点に限定。既存の残高・ルール・保存形式・精算・操作UIは維持。

## 変更

- 下端から上方向だけだった絞りを、上下左右・四隅からの操作へ拡張。つかんだ位置に合わせて折り目を決め、紙面のx/y両方向を円筒曲げする。単に縦の進行率を横入力にも割り当てた処理ではない。
- 指を戻すと閉じる、途中で別の辺をつかみ直す、pointercancel/lostcaptureでつかみ状態だけ解除、カードの外側のタップで勝手に公開しない。タップ・Enter・すべて公開は維持。
- 動き軽減/WebGL不可時も同じ方向の折り目に対応する切り抜き表示。代替表示の当たり領域もカードの縦横比へ合わせた。
- 卓は参考サイトの長所を取り入れ、はっきりした緑のフェルト、金の二重レール、弧を描く卓上文字と配当表記、金の丸みのあるベット枠へ。現在の44px以上のボタン、カードサイズ、スマホのスクロール、PCの履歴は維持。
