# Vesper / Unity community chips

Six original SVG chip designs use ivory, garnet, petrol blue, jade, plum and charcoal clay. Each denomination has a different edge-insert count or stripe arrangement. Beveled rims, inset gold medal collars, fine concentric and intersecting etching, face grain and a restrained community crest provide physical detail without bloom. Large outlined vector numerals survive 44px rendering; the ivory chip uses dark ink for contrast.

All geometry, material gradients, engraving and layouts were authored specifically here by `tools/generate-baccarat-chips.py`. No reference site assets or code were used. The only supplied artwork is `public/baccarat/art/unity-engraving.png`, the Unity **community heart/cup** mark. Its original RGBA image is embedded directly with alpha preserved; it is not the Unity Technologies logo. Numerals are converted to paths from the locally installed DejaVu Serif Bold (DejaVu fonts license); runtime requires no font or network access. Regeneration uses Python fontTools and the local DejaVu font, not a new app dependency.

`CHIP_DENOMINATIONS` is frozen, descending `[50000,10000,5000,1000,500,100]`, in wallet hundredths. Visible denominations are `500,100,50,10,5,1`. `chipAsset(denomination)` returns `./chips/<denomination>.svg` and rejects unsupported values. `wagerChips(amount, maxVisible=5)` accepts nonnegative safe integer wallet values and integer caps 1–12. It returns `{visible, hiddenCount, totalCount}` with a greedy descending visible list and exact counts computed using BigInt. Residual wallet fractions below 100 cannot be represented by these chips and stay in the authoritative wager label. Work and allocations are bounded by six denominations and at most 12 visible chips even at maximum safe integer inputs.

Verification: the arithmetic test was observed failing before implementation, then passing. Chromium successfully decoded all 12 proof images at 200px and 44px. `chip-proof.png` records the rendering comparison. The ivory numeral was darkened after inspection to improve small-size contrast.
