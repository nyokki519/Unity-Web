Original table audio QA — 2026-10-29

New samples are generated by `tools/generate-baccarat-audio.py` from deterministic oscillators and filtered noise, with no recordings, copied reference music, external samples or services. The existing 49.23-second original lounge loop and forecast/win/reveal assets retain their bytes.

`chip` (105 ms) combines damped, inharmonic clay-like resonances and a soft edge contact. `card` (160 ms) is moving paper; `land` (120 ms) is a lower paper contact. `lock` (340 ms) joins a low clasp with a secondary edge contact. `third` (650 ms) uses unresolved filtered air and a low rising body. `result-2` (1.55 s) and `result-3` (2.25 s) extend the original win bed with delayed original arpeggios. All are MP3, with declared source duration and bytes in the manifest.

API additions: `event('lock')`, `event('third')`, `event('land')`, and `roundResult(receipt)`. Existing event names and public methods remain available. The result method imports the shared pure payoutTier helper: no positive net is tier 0, 100,000+ is tier 3, 10,000+ or a profitable tie is tier 2, other wins tier 1. Result extensions use resultVolume; foley uses se; forecasts retain forecastVolume. Multiple samples overlap without replacing one another; the existing 20-voice limit remains.
