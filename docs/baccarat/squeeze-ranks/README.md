# 絞り中のランク表示を抑制

2026-10-30。絞り専用のカード画像を用意し、両隅の2〜10/A/J/Q/Kだけを除去。スート、中央のピップ、絵札、Unityの意匠は維持。

- WebGLの720×1000テクスチャと、WebGL非対応／動き低減のフォールバックが同じランクなしSVGを使用。
- SVGの遅延・失敗中も、同期的な両隅のマスクで元アトラスの数字を表示しない。
- 絞り中の読み上げラベルもランクを含めない。
- 公開確定後は従来の通常カードを表示し、数字と正確な読み上げを復帰。通常カード、アトラス、ルール、精算、全方向の曲げは変更しない。

検証：52枚すべてで両隅2箇所のランクだけを除去、通常マスター不変。ブラウザの実画素比較で両隅10,898画素のみが変化し、中央部の差分0。実WebGLテクスチャがランクなしSVGと完全一致。フォールバックと公開後通常カードを確認。既存ライフサイクルと全方向22項目も成功。

証拠：[ブラウザ結果](report.json)、[フォールバック](fallback-no-number.png)、[WebGL](webgl-no-number.png)、[各ログ](results/)。Chromium検証であり、実機iPhone/Safariは未確認。
