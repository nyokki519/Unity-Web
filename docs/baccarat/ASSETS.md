# 素材・利用条件

| 対象 | 出所 | 配布・取り扱い |
|---|---|---|
| カード52枚・裏面・幾何学紋章 | 本プロジェクト向けの正確なSVG組版とオリジナル絵札画像 | 第三者のカジノ画像やUnity Technologies公式ロゴを流用しない。原稿と生成スクリプトを同梱。 |
| テーブル・革縁・金属・フェルト表現 | 独自のCSS形状・グラデーションと自作素材画像 | フェルト・革・紙は生成スクリプト、サロンと絵札は本作向け画像生成。出所は `public/baccarat/art/PROVENANCE.md`。 |
| 音・BGM | 独自のWeb Audio合成 | 録音音源・既存曲・既存ゲーム音を流用しない。 |
| 数字・ランク・UIの文字 | 端末にあるシステムフォントを参照 | フォントファイルを配布しない。カードにもフォントデータを埋め込まない。 |
| 絞り・扉/封印/星光・希少色枠・結果粒子 | 新作CSSマスク/幾何学/アニメーション | 外部画像・ロゴ・キャラクターなし。 |
| 予告ベル・紙擦れ | 新作Web Audio合成 | 外部録音なし。音量個別。 |
| Web API | DOM/CSS/SVG/WebGL（絞りのカードのみ）/Web Audio/Web Crypto | ランタイム用の第三者パッケージ追加なし。 |
| サイトの既存アイコン | Unity MIXコミュニティ既存のハートとカップ | 利用許可済み。透過の刻印版をカード・チップにも採用。Unity Technologiesのロゴではない。 |

カードは500×700のベクター座標。スートは独自に記述したパス、ランクは正確な文字組み。Aと裏面の装飾はベクターで管理し、J/Q/Kには専用のオリジナル肖像3種を使用（スート間で肖像を共有）。赤黒だけでなくスート形状でも判別する。裏面は上半分と180度反転した同じ構成を組み合わせ、全カードで共通。

Web版ではSVGを使うため、Unity用テクスチャ圧縮やアトラスは使用しない。将来Unityへ移植する場合に書き出し解像度・圧縮・アトラスを別途検証する。現状をUnity素材設定の検証済みと扱わない。

再生成：`python tools/generate-baccarat-cards.py`。生成済みパックは通信状態によってカード面の表示が遅れにくいよう最初に読み込むが、全画像を一度にデコードする処理は行わない。

VESPERは仮の作品名。商用販売に向けた商標調査・ストア審査・法的適合性の確認は今回実施していない。商用利用条件未確認の第三者素材を組み込んだものではないが、商用品質や法的確認の完了を保証する文書ではない。

音響v2：`public/baccarat/audio/` のラウンジBGMと予告/公開/利益音は `tools/generate-baccarat-audio.py` で制作したオリジナル曲・合成音。78 BPM・16小節、エレピ/ベース/弱いブラシ。元録音・既存曲のコピー・外部音源なし。生成時のみnumpy/scipy/ffmpegを使用（ゲーム実行の追加依存なし）。MP3の生成メタデータは同梱manifest参照。

## 2026-10-29 table release

6額面のチップSVGは `tools/generate-baccarat-chips.py` で新規制作。立体的な側面、樹脂の挿し色、表面粒子、正確な額面、コミュニティ刻印を統一。外部のチップ画像は未使用。

着地・配札・受付終了・第三カード・2段階の配当音は同梱の合成スクリプトで新規制作。サンプルを実イベントで鳴らし、BGM・効果・予告・結果の音量を分離。既存レトロの第三者音源も今回のバカラには転用していない。
