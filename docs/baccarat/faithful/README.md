## 検証

Node全413件成功、失敗0。[実行ログ](results/classic-final-node.txt)。第三カード規則・タイ・95%コミッション・残高・シュー・保存の既存テストを含む。

ブラウザで第三カードのある実ラウンド、DEAL連打、リベット、再読込、375/390/414px、PC、キーボード、Max/Min/Clear、音量保存を確認。保存失敗を各境界で注入し、再試行・復帰・二重精算防止を検証。決済結果保存時、リベットYesの3境界とNo、起動時容量不足、ストレージ拒否、必須素材・ダイアログライブラリ不足、配札中の音設定、ホーム中断を含む。修正前の失敗と修正後の成功を確認した。各ログは results/ 内。

既存VESPER画面、Unity MIX作成フォーム、チンチロの玉数保存、レトロの200枚消費、シューティング実射撃、撤去済みmechanicalの410を回帰確認。既存ゲームの物理・通信コードは変更していない。

## 性能と残る差

ソフトウェアGPUのHeadless Chromiumで8秒間、実描画回数を測定。390px:21.42fps、描画間隔中央値49.9ms/p95 50.9ms、1920px:21.33fps、49.9ms/p95 51.0ms。参考のSaveCPU上限30fpsを維持しているが、30/60fps達成とはいえない。rAF回数を描画FPSとして数えていない。カードを52枚の大型SVGから単一アトラスへ変更し、理論上のRGBA面積を約72.8MBから7.5MBへ削減。GPU実割当量ではない。[測定](results/performance.json)。

残る差は以下。画面全体・全機能がカード以外完全一致したという報告ではない。

- Unityのカード絵柄・裏面、ローカルのPlayer名。カードの数字・スートは独自の正確な組版。
- 参考側のアカウント・購入・広告・追跡・ポータルは移植しない。ローカルの保存・新規開始・ルール・罫線をメニューへ配置。
- 既存の8デッキと1/100単位の正確なBANKER配当を維持。参考コードは各回52枚シャッフル・整数丸めであり、この点は一致しない。結果の先決めや勝率補正なし。
- 参考側で実際に確認したのはナチュラル8と第三カードのある複数ラウンド等。全勝敗の音演出を原典で網羅観察したとはしない。
- モバイルSafari/iPhone実機、実スピーカー、ネイティブGPUでの性能・長時間稼働は未確認。動画の同時録画は性能評価に使用していない。

最終性能測定は不要になった参考側ブラウザを閉じ、他のテスト終了後に単独で再測定した値。
