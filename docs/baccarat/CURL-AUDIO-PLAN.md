# 絞り・音響改修 2026-10-28

ユーザーから、マスク式の絞り・単純持続音BGM・短い電子音では質が足りないと指摘。既存の抽選・精算・保存計画は保護。

選択：裏紙のマスクを増やす案では厚みと曲がりが出ない。全面WebGL化は画面構造/端末依存が大きい。最初にCanvas2Dの三角形転写を試したが、曲面に目立つ継ぎ目が出たため不採用。独立した小さなWebGLキャンバスの両面テクスチャ付き曲面メッシュを採用。画面全体は引き続きDOM。曲面を透視投影し、曲率による陰影・縁・浮いた影を描く。裏から実カードの表が現れ、最終的に表が平らになる。指・マウス・range操作と途中保存は維持。通常の最後のカードを操作中だけ再描画し、静止時のアニメーションループは作らない。GPUコンテキストは1枚のキャンバスを繰り返し利用。WebGL非対応/コンテキスト喪失では簡易表示と理由を示し、操作を維持。高DPRは上限2。

音楽：オリジナルの78 BPM、16小節のラウンジジャズ。エレピの拡張和音、ウッドベース風プラック、弱いブラシ/シェーカー。録音流用や既存曲の写譜なし。再生成用スクリプトを同梱。MP3でiPhone互換を優先し、Web Audioの個別音量へ接続。絞り中は音楽をダック、停止中は曲も停止、復帰時に続きから。

音：配札は紙、チップは短い硬質接触、絞りは動かした時のみ紙擦れ、予告は段階別のベル/上昇音、利益確定は短いオリジナルの解放和音。色だけの差ではなく音の構成・余韻を分ける。耳障りな高音・長いノイズは避ける。音源ゲインとリミッター、発音間隔/声数の上限を維持。

順序：1 曲面の数式と両面判定テスト → 2 独立描画器とUI統合 → 3 音楽生成と音響統合 → 4 同条件の操作録画/音源確認・スマホ幅・再接続・既存ルール/回帰 → 5 公開と公開後検証。

受入：0%裏/100%表、途中に曲面と両面が存在、幾何連続/NaNなし、実カードの目のみ、100%未満で合計点非公開、保持/再読込/短縮可。BGMループ/デコード/無音区間/ピーク、音量ゼロ、非表示停止、復帰で音楽重複なし。375/390/414pxと1080pの操作・コールバック間隔を確認。実機iPhone/実スピーカー未確認は区別して報告。


## 実装・検証結果

- 曲面モデルは伸びない紙を円筒状に折り返す幾何近似。紙の弾性や指との接触を解く剛体/有限要素シミュレーションではない。独立したWebGL1の小面積描画。既存Three.jsなどのライブラリ追加なし。非対応端末では理由と簡易表示を示す。
- 原稿の表/裏を同じ曲面へ貼り、深度バッファで前後を判定。試作Canvas転写の継ぎ目は採用版には残さない。GPUコンテキストを1枚の共有canvasで再利用し、カードごとにテクスチャ/バッファ/プログラムを解放。更新は操作時/自動絞り中/サイズ変更時のみ。
- 全体385 Nodeテスト成功。曲面の0%裏/100%表、途中の両面、連続性/有限座標、音源同梱/配信MIMEを追加検証。第三カード/精算/保存/演出独立乱数など既存テストも維持。
- 実ブラウザ：0/20/40/55/75/95%の曲面、100%まで公開点数を維持、保持/復帰、375/390/414px、日英130%、range/タッチ/マウス、短縮を確認。BGM49.23秒/loop/再生可能状態、ミュートで停止・再開で同じ位置から、音楽要素が重複しないことを確認。
- 画像読込み中のGPU喪失→遅れて到着した画像が簡易表示を隠す競合を失敗テストで再現して修正。失われた描画器を破棄して簡易表示を保持し、100%公開から精算まで遊べることを確認。
- BGMデコード後ピーク0.684、RMS0.127、0.5秒ごとの最低RMS0.0747、ループ境界のサンプル差0.00347。全7音源でピーク1未満・無音ファイルなし。これは聴感の品質を保証する数値ではない。
- 測定（Chromium、華やか/自動絞り、各3ラウンド）：390px rAF中央値16.7ms・95%点16.7ms・最大33.3ms、1920px中央値16.7ms・95%点16.8ms・最大33.4ms。Long Taskともに0。実ディスプレイFPS/実機iPhone測定ではない。
- 旧バカラ操作/演出、Unity MIX作成画面、チンチロ1投とコイン保存、レトロ単発と200消費、シューティング実射撃、旧役物410の回帰成功。
- 共有サーバーへの変更は `.mp3` の正しい `audio/mpeg` MIME追加のみ。ルール・抽選・賭け金・賞金・既存ゲームのコードは変更しない。

未確認：実機iPhone/Safari/VoiceOver、実スピーカーでの最終音量バランス、長時間実機稼働。カフェらしさや気持ちよさは自動テストで完成と断定せず、実際の試遊で追加調整する。
