# Unity Baccarat — オリジナルテーブル版

既定入口 `/baccarat/index.html`。参考サイトの再現から方針を変更し、レビューされた14状態の問題を対象に、Unityコミュニティの独自デザイン・直接操作へ改修。既存のルール・8デッキ・整数精算・残高・保存形式を保護。

## 実装

- 深いネイビー、エメラルド、アイボリー、真鍮の新規タイトル・フェルト・チップ・ボタン・結果・設定画面。元サイトのPNG/フォント/SEを新画面から読み込まない。コミュニティのハート/カップを透過したブランド素材、専用カード・額面別チップ、繊維感とテーブルの縁。
- スマホ専用の流れる配置、PCの横長テーブルとライブ履歴。固定640px縮小を廃止。主要ボタン44px以上、safe-area、縦スクロール、キーボード・フォーカス表示。
- 額面選択→賭け先タップでベット。1操作取消、全解除、前回ベット、最大ベット、残高不足/上限/最低額の説明。新規は50,000、以前の保存は残高・テーブルを維持。
- カードは読みやすい幅を保ち重ねる。絞りは指/マウスで紙の下端を直接持ち上げ、分割メッシュの曲がり・表裏・影を変化。拡大時だけ720×1000の元SVGからの画像を使い、閉じる時にWebGLコンテキストとテクスチャを解放。単なる進行バーではない。
- 絞りは重要カード/全カード/自動を選択。タップ・Enterで公開、すべて公開、動き軽減、クイック。WebGL不可時も指で覗ける代替表示を用意。
- 強制リベット窓を廃止し、勝敗→元本返却/配当利益/受取合計/純収支→次の操作を画面内へ。損失・返却を勝利と区別し、勝利時のみ控えめなチップ移動を表示。
- プレイ中と絞り中から履歴・罫線・設定へアクセス。ネイティブdialogでフォーカスを保持、Escapeで閉じる。履歴はビーズプレート/大路/直近500局/全セッション統計、集計分母を明示。
- オリジナルのWebAudioラウンジ和音、チップ/配札/公開/結果/配当の独立した音。BGM/効果音/UI音を別調整、音量%と全音OFF、操作前の自動再生なし、発音数上限と背景停止。
- 保存失敗時は確定前状態を保持し、再試行または明示的な一時プレイ。各カード公開もチェックポイント保存。中断後は公開済み位置から再開。重複配札・二重精算を既存Sessionで防ぐ。

現在の主画面: [タイトル](title-390.png)、[ベット](bet-390.png)、[絞り](squeeze-390.png)、[結果](result-390.png)、[PC](viewport-1440.png)。[音付き実操作動画](round-with-audio.mp4) は検証用の合法な固定シューを使った実録画。公開される通常ゲームに固定勝敗は設定していない。

## 分担と技術

並列担当をshell/CSS、絞り、独自アート/音、独立QAに分割し、ルート担当が金融アダプター・進行・パネルと統合を担当。ファイル境界・APIを先に決定して編集衝突を防止。別のレビュアーがイベント・保存復旧・モーダルの優先順位を確認した。

- salon-controller.js:既存SessionへのUIアダプター。金額は1/100チップ単位。
- salon-round.js:公開と待機・中断。結果や乱数を変更しない。
- salon-main.js:表示・入力・復旧の統合。
- salon-panels.js:設定・ルール・履歴。
- salon-shell.js/salon.css/salon-panels.css:独立したレスポンシブUI。
- salon-squeeze.js/salon-card.js:立体カードと代替操作。
- salon-art.js/salon-audio.js/salon-assets/:オリジナル素材。

以前の再現版は `/baccarat/classic.html`、VESPERは `/baccarat/vesper.html` に保存。ルール・精算・シュー・保存モジュール、他ゲーム、サーバーは変更していない。

## 検証結果

- Node全420件、失敗0。[ログ](results/node-tests.txt)
- 独立Playwright14グループ成功。正確なBANKER0.95利益、タイ8倍とメイン返却、第三カード6枚、実際のドラッグ、スキップ、中断/再読込、再試行、モーダル/キーボード、375/390/414/1440px、44px/ボタン重なり/横溢れ/6枚の自分側領域を検証。[QA](results/qa-report.md)
- 失敗注入:起動容量不足、保存拒否、一時プレイ、confirm/公開チェックポイント/settle/next/rebet/reset、連続失敗後の再試行。保存不成立時は残高・履歴不変、復帰後1回だけ精算。
- レビューで発見したモーダルと絞りのEscape/Tab競合、再試行の多重ラッパーが失敗を隠す問題、非同期公開の復旧後に古い警告が残る問題を修正。[独立レビュー](results/review.md)
- VESPERの広範囲ブラウザテストと直接手動公開、Unity MIX作成画面・交流モード、チンチロ投擲/残高保存、レトロ単発/200枚消費、シューティング実射撃、mechanical410を確認。

## 性能・未確認事項

同時ベンチマークや録画を止めたHeadless Chromium/ソフトウェアGPUで測定。通常画面のrequestAnimationFrame間隔は390px/1920pxとも中央値16.7ms、p95 16.7ms。これは実コンポジターのFPSを計測したものではない。実際のドラッグ44回の曲面更新/WebGL送信は中央値1.0ms、p95スマホ設定1.6ms/PC1.8ms。GPU完了時間ではない。[生データ](results/performance.json)

物理iPhone/SafariのURLバー・音声実機・GPU性能は未確認。実測端末で60fps保証、商用完成認証、無期限の安定性確認はしていない。元の低解像度画像を無理に全画面化せず、絞りのみ高解像度を使う。音付き動画に記録された音は実際の生成音だが、実スピーカーでの聴感評価は必要。

## 素材と権利

Unityはコミュニティ名でありゲームエンジンのロゴではない。既存のコミュニティアイコン・専用カードを使用。新しいチップ/フェルト/透過マーク/タイトル画像は同じ意匠から生成した独自SVG。音楽・効果音は本作のオリジナルWebAudio合成。Three.jsは既存のMITライブラリ、Cormorant Garamondは既存OFLフォント（public/assets/fonts/OFL-CormorantGaramond.txt）。新しい外部サービス・課金素材・解析送信なし。許諾済み参考素材は旧画面用に保管し、新UIでは呼び出さない。

起動: `npm install`（Node24以上）、`npm start`、`http://localhost:3000/baccarat/index.html`（PORT設定に従う）。テストは`npm test`、`UNITY_URL=http://localhost:3000 python test/baccarat-salon_browser.py`。通常の公開は既存Render設定を利用。リリース確認記録は公開後に追記する。

改善前後: [タイトル](before-after-title.png)、[盤面](before-after-table.png)。いずれも390px幅の実画面。共有コードの変更はUnity MIXホームのバカラ紹介文1か所のみ（ベット操作順の説明を更新）。旧画面テストは`BACCARAT_VARIANT=classic|vesper python tools/baccarat-retained-qa.py 対象test.py`で実行できる。
