# Unityロゴ・コインと積み上げベット — 2026-10-30

ユーザー指定のロゴ/コイン/ベット表現だけを変更。受け入れ済みの緑の卓、点線円形領域、紫のタイトル背景、配色、全方向絞りは維持。

- ロゴ：参考サイトの筆記体画像を外し、Unity専用の直立セリフ体と幾何学装飾によるオリジナルSVGへ。既存OFL Cormorant Garamondをアウトライン化し、機種のフォント差・文字化けを防止。タイトル/卓の両方を差し替え。
- コイン：参考サイトの画像スプライトを外し、Unityコミュニティの印を刻んだ既存オリジナルの額面別コインを使用。四角い選択ボタンの見た目をなくし、丸いコイン自体を押す表現。キーボードと44pxのnative button操作は保持。
- 操作：PLAYER/TIE/BANKERを先に選択。その選択だけでは金額は増えない。額面コインを押すたび、選択した領域へコインを追加し、着地と重なりを表示。
- 表示：確定済みのベットとundoスナップショットから積み上げを再構築。連続して100を3回なら100コイン3枚。取り消し・全解除・前回ベット・再読み込みに追従。多い場合は最大5枚を描画し、正確な総額は従来の金額表示を使用する。
- 保存失敗時：未成立のコインを見せず、再試行後に1回だけ追加。UIのコイン表示から精算額を計算しない。Session/ルール/シュー/保存形式/精算処理は変更していない。
