## 画面と素材

ミッドナイトネイビー、エメラルド、アイボリー、シャンパンの体系。既存のオリジナルサロン画像、専用絵札、精密な数字とスート、自作紙・フェルト・革を維持して操作レイアウトを再構成。通常は静か、勝負決着時だけ手札の反射、点数、チップ、短い音を展開する。

新チップは1/5/10/50/100/500を個別SVG化。縁の分割・金属輪・成形した側面・表面粒子・ハートとカップのコミュニティ刻印を作成。額面分解は整数計算、表示上限を超えた枚数は+表示とし、残額を勝手に丸めない。素材出所は [ASSETS](../ASSETS.md) と [原画記録](../../../public/baccarat/art/PROVENANCE.md)。新規の第三者録音・ブランド素材は未使用。

## 1ラウンド

受付終了音→シューからカード移動→反転→着地音→第三カードの予兆→公開→精算確定→勝者領域の局所照明→元本返却/損失回収→利益チップ→余韻。通常500msの移動/420ms反転、クイック180/160ms。結果演出は120ms予兆・250msの衝撃・1300ms以内の余韻。利益がないラウンドを祝勝演出にしない。

粒子・チップ等の装飾ノードは合計24以下。クイック、即時、動きを減らす設定、非表示、途中停止、スキップ、次ラウンドで破棄。演出処理からカード・乱数・残高を変更しない。音はオリジナル制作の紙・チップ・受付終了・第三カード・利益音を実イベントに同期。種類別の短時間制御により、同じ瞬間のカード音が第三カード音を消さない。BGM/予告/結果/効果の再生系は独立。

## 検証

- `npm test`: **407 passed, 0 failed**。第三カード全分岐、ナチュラル、タイ返却、コミッション、残高、重複精算、シュー整合性、罫線などを含む。
- 実ブラウザ: ベットから次ラウンド、連打、リロード後の同額復帰、履歴、設定、3段階チュートリアル、保存拒否/容量不足、日英/130%文字、各画面幅。
- 隔離した既知シューの6場面: 参考同条件の勝利、バンカー5%控除、タイ返却、タイ的中、敗北、大きな利益。全て実UIから精算、読み取り用フックで照合。これらは確率測定用サンプルではない。
- 実タッチ・マウス・キーボードで直接絞り、戻し、長押し、再開。GPUコンテキスト喪失時のフォールバック。
- レビューで発見した「スキップ後の予約反転」「Escape停止後の残留反転」は失敗を再現し、キャンセルと実面表示を修正して再検証。
- 手札一括拡大は44pxボタン、115px以上のカード。先のカードを混入させない。
- 既存Unity MIXの作成画面、チンチロのロールとコイン、レトロの発射200消費、シューティングの出撃/射撃をブラウザで回帰。撤去済みmechanicalは410を維持。他ゲームのコードは未変更。

### 描画と性能

カード絞りは毎フレームのCPUメッシュ構築・バッファ転送を廃止し、固定729頂点/3840インデックスと頂点シェーダーへ移行。同じ曲面・投影範囲・材質を維持。15姿勢の画素比較で最大平均誤差0.00781/255、4以上異なるチャンネルは最大0.02225%。120回描画×5測定の中央値117→5ms。ただしこれは描画投入の局所測定であり、FPSではない。

元の版と同一シュー・同一演出IDで、1回ウォームアップ後3ラウンドを順次測定。rAF中央値は約16.7ms。全画面実行ではソフトウェア描画の遅延が残る。テーブル合成面とカードを分離した比較で1920幅通常演出のp95は66.6→49.9ms、最大166.6→133.4msだった。改善前の通常演出p95の16.8msには届いていない。60fps安定達成と扱わない。全測定は同梱JSON、実機iPhone/GPUでの性能とは区別する。

## 残る課題・未確認

- 物理iPhone Safari、実スピーカー、実GPU端末の60fps・発熱・バッテリー・ブラウザUIとの相互作用は未検証。
- PC幅のソフトウェア描画のフレーム遅延が残り、商用推奨端末の基準測定が必要。
- 今回は既存BGMを維持し、接触・第三カード・配当音を更新。市販音源や参考サイトの音は使っていない。
- 絵札は独自肖像3種を4スートで共有。12種類の独立した絵画ではない。仮ダミー機能の表示は追加していない。
- 参考サイトの履歴/罫線、全分岐、長時間品質は未確認。販売前の商標調査・ストア審査・正式QA認証は別途必要。

起動: Node24以上、`npm ci`→`npm start`→`http://localhost:3000/baccarat/index.html`。追加の有料サービス・鍵・環境変数は不要。
