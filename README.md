# UNITY MIX

**遊ぶほど、その人が見えてくる。**

目の前の人との会話を楽しむ、2〜24人用のリアルタイムWebゲームです。それぞれのスマートフォンから同じルームに参加し、秘密の回答 → 同時公開 → 理由を話す、を楽しみます。アカウント登録は不要です。

## はじめる

Node.js **24以上**。

Render無料公開向けの設定は `render.yaml`、手順は [公開準備](docs/DEPLOYMENT.md) を参照してください。

```bash
npm ci --ignore-scripts
npm start
```

サーバーは既定で `0.0.0.0:3000` に待ち受けます。同じWi-Fiの別端末から遊ぶときは、このサーバーのLANアドレスでアクセスしてください。`localhost`は他の端末から参加できる住所ではありません。

ホストがルームをつくり、QRか4桁コードを共有。名前を入力し、全員が「準備できた」を押したらスタートします。

## 1人用のおまけ：喫茶・銀環

ホームの「大穴チャレンジで遊ぶ」から、釘・回転機構・開閉入口・三段クルーンへ挑む日本語3Dゲームへ入れます。登録・ルーム作成は不要。作者からの改変・公開許可がある旨のユーザー申告に基づき、参考ゲームのコードを使用しています。[起動・操作・技術設計・機能比較・検証](docs/boqingge-study/IMPLEMENTATION.md)、[権利・素材一覧](docs/boqingge-study/RIGHTS.md)。旧接触物理モデルは `/?bonus=jackpot&physics=1` で利用できます。

## 対面イベント用6ゲーム

ルーム作成時の「イベントゲーム」から、価値観ランキング／この回答、誰でしょう？／みんなの境界線／共通点クエスト／架空のカフェ会議／エピソードの持ち主を選べます。各15題、司会のお題編集・追加、チーム分け、締切、匿名予想と正解公開、回答の非表示・参加者退出に対応します。

[遊び方・公開範囲・時間設定・起動方法](docs/EVENT-GAMES.md) を参照してください。既存6モードと共有機能は保持しています。

## 既存の6モード

| モード | 体験 |
| --- | --- |
| ALIGN | 秘密の二択。人数・割合・名前を公開して、違いの理由を話す |
| PREDICT | 一人の答えを予想。本人の回答と的中人数を公開 |
| LINE | 0〜100のスライダー。匿名の分布・平均・最小・最大 |
| RANK | ドラッグまたは上下ボタンで順位づけ。グループ順位と自分の順位 |
| AUCTION | 合計100ポイントを自由に配分。グループ平均と自分の配分 |
| QUICK MIX | 短文を入力、または口頭だけで話す。パスもOK |

「おまかせMIX」は6モードを順に出題します。LIGHT / BALANCED / DEEP、カテゴリ、お題数、自動公開 / ホストによる公開を選べます。全員の回答前には公開できません。お題は使い回さず、プールが設定数より少ない場合は使える数に調整します。

現在252問。質問・カテゴリ・値のラベルは `data/` で編集できます。

## 結果・共有

OUR MIXはグループの回答傾向、YOUR MIXは本人の傾向をまとめます。性格診断ではありません。Quickの言葉や、PREDICTで他人を予想した回答は価値観スコアに混ぜません。

1080×1920の画像を生成して保存できます。対応ブラウザーではWeb Shareも利用できます。画像には名前や個別の回答を載せません。音は出ません。

## 再接続・公開範囲

- 同じブラウザー・端末は保存した参加情報で復帰します。回答途中の下書きはタブのセッション内に保持します。
- 同じ参加情報を別タブで開くと、後から開いたタブを使います。
- ゲーム途中の新規参加者は次のお題から参加できます。
- ホスト切断から12秒後、接続中の参加者にホスト権限を移します。旧ホストの復帰で権限を勝手に戻しません。
- 切断中・未回答の人を待つか、そのお題のみパス扱いにするかはホストが選べます。
- 回答前の他人の値は、クライアントへ送信しません。LINEは匿名、個人の順位・配分・YOUR MIXは本人だけへ送信します。
- ローカルSQLiteに一時保持。未使用24時間、ゲーム終了から1時間で削除対象。復帰用の生トークンはDBへ保存しません。

詳細は [設計と運用](docs/ARCHITECTURE.md)、[検証結果](docs/QA.md) を参照してください。

## 公開する

これはNode.js＋WebSocketアプリです。GitHub Pagesなどの**静的ホスティングだけでは動作しません**。旧HPのデプロイ先はリポジトリから特定できなかったため、本番のURL変更や公開は行っていません。

Node対応のホスティングまたは自分のサーバーで、一つのプロセスとして動かします。

| 変数 | 既定値・用途 |
| --- | --- |
| `PORT` | `3000` |
| `HOST` | `0.0.0.0` |
| `PUBLIC_URL` | 公開時に実際のHTTPS originを指定。QRの参加先に使う |
| `DATA_PATH` | `.data/rooms.sqlite`。永続ディスク上の非公開パスを推奨 |

HTTPSとWebSocketのUpgradeを有効にしてください。SQLiteのデータディレクトリを静的公開しないでください。複数プロセスや複数インスタンスに水平分散する構成には対応していません。サーバー再起動後も同じDBファイルを使えば復帰できます。

Dockerfileのビルドと、コンテナ内での実マルチプレイヤー通し検証が完了しています。コンテナ利用時は `/app/.data` を永続化します。本番公開とiPhone/Android実機でのQR・共有操作は、公開先が決まってから検証が必要です。

## 開発・テスト

```bash
npm run dev
npm run check:questions
npm test
```

実際のブラウザー2コンテキストによる通し検証（Python Playwright、Chromium、Pillowが必要）：

```bash
python3 test/browser_check.py --url http://127.0.0.1:3000
```

任意で `--axe /path/to/axe.min.js` を指定してアクセシビリティ自動検査を追加できます。ブラウザーテストはテスト用ルームを実際に作ります。専用の検証インスタンスで実施してください。

## ファイル構成

```text
public/           ブラウザー画面、ブランド素材、PWA
src/server.js     HTTP、WebSocket、接続管理
src/engine.js     ルームとゲームの状態遷移
src/modes/        モードごとの入力検証・結果・集計
src/questions.js  質問プールと出題
src/summary.js    OUR MIX / YOUR MIX
src/store.js      SQLite、一時保存・期限切れ削除
data/             質問とカテゴリ
 test/            エンジン・通信・ブラウザー検証
```

Unityのカップとハートの図柄は既存ロゴから余白のみを切り出しています。形を描き直したり、新しいロゴを生成したりしていません。オリジナル全体も `public/assets/unity-logo.webp` に保持しています。既存のCormorant GaramondはOFLライセンスとともに継承しています。旧HP専用の写真・ページ・紹介文はゲームから取り除いています。

## おまけのSI・3D物理版

`npm ci` → `npm start`。ホームの「大穴チャレンジで遊ぶ」から登録なしで開始できます。強さを調整し、単発または長押しで発射します。練習は大きい穴、通常・高難度は狭い入口と小さい穴になります。LABでは各段の成功・失敗を確認できます。

物理の調整場所は `public/js/abyss/si-config.js`、`board-routes.js`、`tray-layout.js`（m・s・kg）。描画は同じ形状を使用します。依存物の再配置は `npm run vendor:physics`。追加のAPIキーや外部サービス設定は不要です。WebAssemblyを許可するCSPと`.mjs`のMIME設定はサーバーに含みます。
